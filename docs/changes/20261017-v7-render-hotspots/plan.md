# 最终实施计划

1. 对照 V6 制作与运行代码，核对 V7.0.3 已有裁切字形/单通道预热，区分制作时绘制、网络等待、解码/上传、重复渲染，不把理论大小当真机崩溃定位。
2. 核算祝福语、城市高精度法线、固定花纸、背景、反射与 V6 新玻璃渲染的开销。只修改 V7，可观察地减小浪费而不降分辨率或改变字形/金属材质。
3. 将声明了准确字节长度的网络与法线解压流直接写入预分配缓冲区，逐块复制后释放源块，不保留完整 chunks 再分配第二个等大数组；严格验证短读、超限和取消，保留字节进度与 SHA256/半精度校验。
4. 城市和文字材质都在局部反射捕获时隐藏的杯壁网格上，移除这些变化引发的无效重新捕获；固定花纸提清时去除第二次重复捕获。保留几何拆解、可见花纸及杯盖平面反射的更新。
5. 对同一组城市与固定相机画面做前后对照，验证正常反射仍更新、图像无变化、单解码队列/取消/恢复无回归。记录原始数据重复分配减少的理论上界与实测浏览器耗时，二者不混用。
6. 完成源码 checkpoint、V7.0.4 独立预览部署、服务端摘要/公共读回和必要线上测试，再提交归档。首次公网预载的已知慢速边界及物理 iPhone 验收继续保留。
