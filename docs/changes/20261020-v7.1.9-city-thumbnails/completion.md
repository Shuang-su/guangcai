# V7.1.9 / v7-8 城市卡片线稿修正

用户截图与本地V7.1.8实际手机视口均复现：深圳卡片只显示局部建筑，邻城也缺失。v7-7杯身R/G贴图中完整建筑群与桥面齐全；缩略图原文件已缺失，不是卡片object-fit裁切。

根因是sharp管线将画布先resize，而joinChannel仍接收原2048×892透明通道，造成尺寸错位和错误颜色。最终修复：完整R线稿先等比缩小至560×244，再按同一目标尺寸组装固定金色RGB与透明度，保留完整原画布。未按单城墨迹裁切或改变杯身布局。

新增不可变v7-8，仅23张缩略图与资源清单改变；城市69档mask/normal、字框/成都覆写、花纸、标记和PSD映射与v7-7规范化路径后完全一致。旧v7-1..7目录未修改。正式与开发iframe默认使用新资源，字框报告中的V7.1.7仍标识原设计版本。
