- 浏览器高层右键未打开蓝湖菜单；在核对专用新tab中使用受支持的CUA CDP鼠标输入完成正常菜单操作。浏览器虚拟剪贴板未接收设计导出，使用Safari本地接收页粘贴系统剪贴板到项目暂存；临时tab已关闭，原用户蓝湖tab保留。未读取编辑器私有状态或私有API。

- 首次展开图合成时Sharp提前resize导致尺寸拒绝，改为先合成完整4096画布再缩小后通过；失败文件未发布。
