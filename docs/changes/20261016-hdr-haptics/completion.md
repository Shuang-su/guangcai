# 完成记录

日期：2026-10-16。Issue #25；分支 `codex/xy-color-material`。本轮为本地开发，产品版本仍为 V5.1。

## 实际改动

- 为两种 XYPad 的激活彩色底图、白色选点增加可选 WebGPU HDR 层；同一 GPU 设备共享，源纹理只在重绘时上传，拖动复用管线和纹理。不支持扩展输出或设备丢失时退回原 SDR 层。
- 针对用户指出的高明度偏色，改为先解码 sRGB 到线性光，再乘曝光增益，最后编码回 sRGB。整盘颜色保留线性通道关系；未扩大明度滑条 20–65 的范围。低端依旧是深色，并保留色相与明暗区别。SDR 回退继续沿用现有亮度反馈；这些激活效果不会修改杯身 HSL 状态。
- 触摸激活、移动刻度、默认点/边界、松手、重置及切换接入短脉冲请求。移动位移以最后一次刻度位置为基准，避免累计微小抖动造成连续震动；共享 55ms 请求间隔。四个触感单元测试覆盖信任、类型、环境、限频、拒绝/抛错、网格位移及 1000 次微抖动。
- 显式声明已有的 `@webgpu/types@0.1.74` 类型开发依赖。锁文件仅增加根声明，不升级现有转依赖。
- 未修改城市资源、填色映射、固定金线、白瓷、花纸、浮雕、杯身渲染链路或既有控制布局。

## 修正过程与已知边界

- 最初直接对 gamma 编码 RGB 施加增益，用户反馈高亮端颜色不正常；最终改成线性曝光。旧 1.58 / 2.13 读回数值不作为最终验收指标。
- 测试初版读取隐藏 canvas 的 clientWidth 为零，导致 GPU 拷贝坐标无效；改为从父容器尺寸计算像素，之后全部回归通过。产品初始化同时增加 ready 防护和错误回退原因。
- 截图是 SDR 捕获，可核对颜色分布和布局，不能证明真实 HDR 峰值亮度。尚未进行实体显示器测光或实际手机马达手感验收。
- iPhone Safari 无通用 Navigator.vibrate；本实现不把原生 switch 的触感当作任意马达接口。需要 iPhone 任意触感时需另行使用原生容器桥接；本轮未加此范围。
- 8/4/8/6/12ms 为首轮试调参数。支持 API 的设备也可能受系统设置、浏览器策略或硬件限制影响。
- 本地预览继续为 http://127.0.0.1:5236/ 。用户已有标签页没有被刷新或关闭；验证使用独立临时页。
