# V5.4.2 短屏幕放大恢复

状态：**V5.4.2 已发布，线上回归及归档校验完成，V5.4.1 脉冲逻辑保留**。基线 9060bba，分支 codex/short-screen-lift，关联 Issue #25。

## 实际修改

根因是短手机视口中城市创作面板的 62% 高度上限不足以容纳原有内容和放大余量，prepareControlLift 因防裁切而把整块倍率压为 1。

仅新增一段短手机响应式 CSS（宽度不超过 520 px、可视高度 521–780 px）：压缩标题和预设间距，隐藏重复的“配色预设”视觉说明（按钮组的可访问名称保留），城市展开行保留至少 24 px；根据当前控件尺寸给出最小面板高度，并保留底部安全区。

色盘、材质盘和明度条原尺寸不缩小；使用既有 1.24 倍放大和原来的动画时长。面板在按下前已经留出空间，按下期间不滚动、不跳高；杯子预览构图代码保持不变。一般高度手机与桌面不应用这段紧凑样式。

protected-haptics.json 固定 7 个文件摘要：脉冲、iOS 原生手势、两种控件、放大计算、面板交互以及杯子构图。发布前与最终源码逐字节核对，保护用户已确认有效的 V5.4.1 行为；诊断面板只有版本字符串随产品更新。没有修改 Safari 识别等待或尝试改变脉冲频率。
