# 完成记录

## 当前实现

V7.0.3 在 V7.0.2 的进入门控上增加完整低清文件预载和邻近高清预取。此前 V7.0.2 的预载范围只有当前城市，所以选择远处城市仍需要请求与解码；本轮把用户指定的城市库范围纳入进入条件。

新增按字节预算的原始文件缓存，网络最多两项并行，纹理解码仍最多一项。固定低清、23 城低清、全部缩略图与六句祝福语不会因高清轮换被淘汰；高清文件可取消并按 LRU 回收。只解码当前城市，避免把 23 城都长期放进显存。恢复 WebGL 时也可直接复用低清文件。

祝福语运行时不是 SVG：裁切的 WebP 遮罩在 CPU 解码/提取单通道后上传为 R8，由现有金属材质 shader 配合 UV rect 渲染。六句下载共 106,722 字节，GPU 含 mipmap 共 2,159,412 字节。现在进入前全部上传，文字切换复用贴图和 shader，不重生成城市图片、不改变字形或材质参数。

默认手机预载 91 项、10,929,425 字节（10.42 MiB），不包含 JS/UI/背景；文件缓存上限 12 MiB。加载页显示这一范围的真实字节、读取速率、图形内存估算、文件缓存及版本 V7.0.3。旧 5 MiB / 6 秒目标与用户新的完整预载选择不兼容，保持未通过标记。

## 边界

浏览器测试的切换毫秒数是桌面软件环境中的事务完成时间，不等于 iPhone 的真实显示响应。真机 30 分钟稳定性、触感和画面验收仍待用户。本轮开始时 V6 玻璃改动尚未提交；本轮城市/文字实现完成后重新读远端，发现它刚形成 2ad92f6（V6.0.3）提交。该提交新建独立 WebGL 玻璃合成器和额外渲染缓冲，未纳入本轮已验证的资源修复；V7 的 UI 同步基线仍为 V6.0.2 / 923a54d。没有改动 V6 工作树或部署。正式后端联调仍属后续阶段。
