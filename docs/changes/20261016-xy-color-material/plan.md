# Issue #25 执行方案：方形调色盘与二维材质控制

## 1. 目标与实施基线

以你最新补充的截图为准，重点还原**彩色方形底图、白色点阵、拖动圆点和附近点阵的动态反馈**。外层容器沿用网页现有风格，不额外开展深浅主题改造。

当前工作区为 V5.1，分支 `codex/city-v5-eleven-source`，提交 `743af2c`，包含 13 套可编辑城市图样，工作树干净。本轮只读检查中，**24 项现有测试与 TypeScript 检查均通过**；这些是实施前基线结果。

实施从该提交建立 `codex/xy-color-material`，关联 [Issue #25](https://github.com/Shuang-su/guangcai/issues/25)。首轮覆盖现有 V5 参数化城市，原版中国款继续使用既有控制方式。

## 2. 先完成共享控件，再替换现有操作区

实现一个原生 TypeScript `XYPad`，颜色、材质各使用一个实例，共享外观与输入逻辑，不引入新的前端框架。

- **布局：**桌面和手机均使用“颜色／材质”切换，在同一位置显示方形面板。五种配色预设和恢复按钮保留；手机端城市选择默认折叠为当前城市入口，展开后复用现有城市列表，让调整盘打开即可看到。
- **外观：**彩色底图使用 Canvas 绘制，点阵独立绘制，白色选点使用 DOM 元素叠加。选点增加细描边和阴影，保证在浅色区域仍清晰。材质盘底色随当前选色，真实材质效果由杯身预览呈现。
- **反馈：**迁移 SwiftUI 参考中“距离越近，点越大、越亮”的逻辑，保留柔和光晕。低动态效果偏好下减少动画，不影响选点反馈。
- **输入：**内部统一输出 `[0,1]` 的二维位置；支持点击、鼠标和触摸拖动、指针捕获、越界限制。只在面板内部阻止滚动与三维旋转，面板外保留原手势。
- **状态同步：**拖动位置立即反馈，材质更新逐帧合并；松手提交最后位置。切换城市、预设、标签页或关闭面板时清理未完成手势，避免旧事件覆盖新状态。
- **可访问性：**提供方向键操作及等价的双轴读屏控件；预设、外部状态更新和面板尺寸改变后，游标同步回到正确位置。

颜色底图仅在尺寸或当前明度变化时重绘；拖动时主要更新点阵、游标与杯身参数。

## 3. 参数映射与兼容

**颜色继续使用现有 HSL 数据。**

方形中心坐标记为 `u、v ∈ [-1,1]`：角度控制色相，`max(|u|, |v|)` 控制饱和度，使整个方形边缘达到最高饱和度。顶部为红色，色相绕中心连续分布；实现坐标与 HSL 的双向转换。

中心饱和度为零时保留上一次有效色相。明度保持当前配色值，继续使用既有深浅渐变关系，因此中心呈现对应明度的中性色，不强制变成白色。调色盘表达基色，杯身仍会受到灯光和材质影响。

**材质复用现有纵轴，只增加一个横轴字段。**

- `Appearance` 保留现有 `material` 作为纵轴，新增可选 `materialX`，缺省为 `0.5`。这样旧数据自然对应 `(0.5, material)`，避免同时维护两套相互冲突的材质坐标。
- 扩展 `materialAt(t, x = 0.5)`；单参数调用继续返回原有结果。
- 横向粗糙度按 `0.75 → 原曲线值 → 0.08` 连续插值，清漆层按 `0 → 原曲线值 → 1` 连续插值；纵向金属度保持 `0–1`。
- 选择原有材质端点的兼容 API 时，同时将横轴恢复到 `0.5`；跨城市切换保留两个方向，恢复配色预设则恢复该预设的原始材质。
- 界面移除旧 HSL 滑杆、材质滑杆、材质端点按钮和浮雕滑杆。保留底层浮雕字段与调试接口，颜色和材质操作不改变浮雕值。

**渲染层必须同步改造。**

现有着色器通过 `v5Blend` 同时计算三项材质参数。改造后，金属度继续使用现有输入，填面粗糙度和清漆层使用独立 uniform；显示与调试信息共用同一个映射函数。

横向扩展仅作用于城市填面。固定金线、白瓷和花纸保留原参数；文字沿用现有纵轴材质规则。继续复用当前贴图与缓存，拖动不触发纹理重建、着色器重编译或环境反射重新捕获。

## 4. 实施顺序与验收

按三个阶段形成可审查提交：

1. **参数与渲染：**补齐二维映射、旧状态兼容和遮罩隔离测试，先验证旧材质曲线能够精确复现。
2. **控件与接入：**完成 `XYPad`、彩色方形分布、点阵反馈、移动端布局和状态同步，保存 SwiftUI 来源版本及 MIT 声明。
3. **回归与证据：**更新现有 V5 浏览器回归，把旧滑杆操作替换为真实点击和拖动，保留原有城市、缓存、加载失败及兼容性检查。

验收覆盖：

- **映射：**颜色中心、边缘、四角、色相首尾及坐标往返；材质九点、中心列、范围边界和非法数值。
- **状态：**恢复预设、颜色／材质切换、跨城市保持、旧 API、快速切换与失败恢复；验证浮雕未被修改。
- **渲染：**北京和深圳在固定相机、固定灯光下做九点材质对照；其余城市检查接入和状态保持。固定金线、白瓷及花纸单独核对。
- **操作：**桌面、手机竖屏和横屏，验证点击、连续拖动、越界、取消、键盘、面板滚动及三维手势。
- **性能：**持续拖动时核对城市资源请求数、纹理数、着色器程序数和反射捕获次数没有新增；不凭截图认定性能通过。

浏览器视觉检查优先使用内置浏览器，自动回归继续使用项目现有 Playwright。浏览器模拟和真实手机结果分别记录。

## 6. 实施中的用户追加（2026-10-16，覆盖对应旧条款）

- 颜色新增右侧竖向明度条，范围 0–100，支持鼠标、触摸、键盘、预设恢复与跨城保留；面板高度不增加。原“明度保持当前配色、不开放控件”改为“首次从预设读取，之后可独立调节”。
- 选点位置直接跟手；按下放大、松开弹性收拢。附近点阵增强尺寸、亮度、光晕及小幅位移，反馈位置短暂跟随；稳定后停止动画，减少动态效果时取消时间缓动与位移。
- 色盘缓存 L=50% 的色相／饱和度底图；明度以黑／白覆盖合成，避免每次拖动重新执行逐像素角度计算。明度不改动色相、饱和度、材质与浮雕。
- 材质仍采用现有二维参数映射，不增加与横轴联动效果重复的第三滑条。
- 扩展真实滑条、明度端点、像素颜色、性能、动态／减少动态效果和窄屏可见性的回归；初版 79 项回归证据保留，追加版证据另存。

## 8. 依据录屏优化激活与焦点反馈（覆盖最初仅调整明度条焦点的方案）

- 按原始时间戳检查录屏全部 730 帧，重点放大首次激活 1.750–2.100 秒、拖动以及 5.135 秒附近收起的帧。保留逐帧索引与选取帧，原录屏不改动。
- 颜色盘、材质盘和明度滑块均用浮起、放大与高光揭示焦点，去掉包围整个控件的酒红色焦点框。
- 二维盘激活时出现宽柔光，在约 340ms 内退去；持续拖动保留跟随选点的局部聚光、点阵响应与更明显的选点抬升。松手回落；键盘焦点使用较轻的同类反馈。
- 光效只画在反馈 Canvas，不修改 HSL 色盘底图或杯身参数。保持输入平面尺寸，扩大后的选点允许越过面板边缘，背景与点阵仍按圆角裁切。
- 明度滑块以小幅放大、白色高光及柔和投影替代外框；不显示文字或数值。
- 减少动态效果时取消激活闪光、缩放与时间缓动，保留静态聚光和高光；稳定后停止 Canvas 动画。
- 验证桌面、手机模拟触摸、键盘、减少动态效果、取消与预设恢复；保存实际操作视频及截图。本地提交，不推送或部署。

## 9. 明度滑条统一为单列点阵

- 保留与色盘等高的 40px 宽胶囊渐变轨道与 44px 触摸区，选择器改为白色圆点，中线采用单列点阵。
- 与二维盘一致：激活宽柔光、选点附近提亮放大与局部聚光、选点浮起，松手柔和回落；减少动态效果下保留静态反馈。
