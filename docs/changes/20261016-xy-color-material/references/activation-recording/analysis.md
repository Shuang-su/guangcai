# 逐帧观察与迁移

录屏共 730 帧，12.583 秒。依照原始时间戳逐帧索引，检查全部十张顺序接触表，再放大关键过渡帧。以下“激活／结束”是根据画面推断的交互阶段，录屏没有提供原始触摸事件。

- 第 92 帧（1.750s）：方形盘约 300px，选点较小，点阵整体较弱。
- 第 93 帧（1.767s）：面板上部出现较宽的白色柔光，亮度变化先于选点充分放大。
- 第 100–111 帧（1.883–2.083s）：面板和选点逐渐放大，选点附近的点阵聚集提亮。
- 第 112 帧（2.100s）：上部的强高光退去，局部点阵聚光仍存在，进入持续拖动状态。
- 第 135–292 帧：选点随拖动移动，附近点阵形成局部亮区；不以包围面板的选中框表达焦点。
- 第 293 帧（5.135s）起再次出现面板上部高光，并逐渐回到小选点／紧凑面板；后续多次重复类似过渡。

网页实现保留“激活宽柔光 → 持续局部聚光 → 松开回落”的层次，选点通过放大与投影产生浮起感。为保持窄屏布局和选色坐标稳定，不复制参考中整个面板约 25% 的缩放，也不增加参考中的数值文字。扩大后的选点不再被面板边缘裁掉。

光效与点阵绘制在独立反馈 Canvas；基础色盘和杯身材质值不受高光污染。减少动态效果时取消脉冲、缩放、位移与时间缓动，保留静态高光。
