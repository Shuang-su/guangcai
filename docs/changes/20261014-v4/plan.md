| 主题 | 款式 | 依据 |

| 中国 | 青绿金线、红金、紫金、蓝金 | 参考图 3—6，保留各自的花、云、鸟等点缀 |

## 2. 素材生成与对齐规范

- 中国建筑由 PSD 锁定。沿用原建筑图层、展开框、相对位置、底部贴齐和已校准的杯身映射。六款共用同一份建筑线条与轮廓，不让 imagegen 分别重画建筑后产生比例漂移。
- 生成负责风格与点缀。使用内置 imagegen，结合对应参考和 PSD 定位图制作配色、釉彩晕染及花云鸟素材。建筑颜色受原轮廓约束，最终描线与凹凸回用 PSD；点缀分层保存，避开文字区和固定广彩边界。
- 深圳先建立统一母稿。以两张参考共同的建筑构图确定一份线条、轮廓和定位母稿，再派生红金与青蓝两款。按同一留白展开规范贴合杯底，避免颜色切换时建筑移动。
- 移除插画背景与烘焙光影。纸纹、白色背景和生成图里的金属高光不进入材质；图案内部的白色花瓣、栏杆等保留。真实反光由三维材质和灯光产生。
- 保存原参考、生成提示词、输出、对齐母版、文字遮罩、轮廓与描线、高度及法线。制作母版保持源稿精度，新款运行贴图采用统一的 4096 × 1783 展开尺寸，数据通道无损保存；高度保留 16 位源文件，新款法线沿用高精度流程。

这些新素材定位为依据参考重建的预览图样，生成的花瓣和晕染不标记为原 PSD 的真实细节。

## 3. 材质与文字接口

拆开图样覆盖、金属分布和线条高度。当前代码把覆盖范围与金属度共用，V4 改成独立数据，保证非金属彩色区域也能正常显示。白瓷补光改为识别图样与文字之外的区域，避免彩釉被当作白瓷提亮。

三种材质共用图样、定位和描线源：
- 彩釉金线：彩色填面采用柔和釉面反光，金线采用金属浅浮雕；蓝紫线描款使用同色凸纹。
- 彩色金属：彩色建筑呈现金属反射，保留配色与较亮的描线。
- 轻浮雕彩绘：降低金属感与线条起伏，以柔和的彩绘釉面为主。

文字独立提供：随款式（中国“中国 / CHINA”，深圳红金“和合共彩”，青蓝“共创美好”）；主题名称（中国“中国 / CHINA”，深圳“深圳 / SHENZHEN”）；深圳可手选任一标语及边框；不显示（同时隐藏文字与边框）。文字颜色随款式，中国纯金保持原金色。中国复用 PSD 字形；深圳文字用逐字检查的独立文字资产，不依赖整张生成图。不提供自由输入。

- 保留 applyCityArtwork(pack)，城市包增加可选覆盖、清漆、法线编码和文字描述；旧包缺省时沿用原行为。
- 增加目录化主题／款式／材质／文字状态，由统一入口加载应用。
- 图样、材质、文字整组成功再切换；失败保留当前效果，连续操作只提交最后一次，释放替换纹理。

## 4. 前台选择与加载行为

- 新增主题与款式入口，主题后以缩略图选配色，下方三种材质与文字。
- 桌面侧面板，移动端可收起底部面板；避免遮挡杯身和观察按钮，校准工具独立。
- 首次中国—原版纯金—随款式文字。首次新款默认彩釉金线，可切另外两种。
- 换款保持相机、缩放、背景。复位只恢复视角，恢复默认款回到中国纯金。
- 不显示文字跨主题保持；深圳专属标语切中国回随款式。刷新恢复默认，不增加账号或云保存。
- 首屏只加载默认款和固定花纸，其他按需；共享线条及通道，不下载全部组合。加载显示目标与进度，保留当前模型。

## 5. 验证与独立发布

视觉验收：中国六款与 PSD 叠图，轮廓、细线、相对位置与底部对齐；深圳两款对照共同母稿。八款各保存三材质同机位对照、建筑／文字面、掠射角及近景；检查彩色、灰模、关闭凹凸。逐字核验标语边框，隐藏无残留。固定高清花纸、器型、结构金边、白瓷回归；纯金与 v3 同机位基线。

功能验收：遍历九款、三材质和适用文字；失败回退、快速切换、旧包兼容、纹理释放。固定装饰不变，彩釉不消失、不误用白瓷补光。桌面、窄屏手机、常用手机、横屏布局，右键／双指拖移、缩放、背景上传、视角切换；模拟与真机分开记录。相关单元、浏览器回归和构建，记录加载，不降低固定花纹清晰度。
