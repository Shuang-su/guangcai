## 实际完成

- 北京拆为长城、三座城楼、央视、中国尊、祈年殿 7 个单元；深圳拆为 7 个塔楼和市民中心主体/屋顶 9 个单元。保存独立 SVG、组合 SVG、构建脚本与来源哈希，后续可逐建筑改稿。
- 祈年殿直接使用原 PSD 提取的 `layer-6-alpha.png` 轮廓，等比进入组合。其余建筑按已有图样编写矢量轮廓和结构线；属于艺术化表达，不宣称建筑测绘准确性。
- 北京央视左侧无多余出线，中央开口留白；长城末端顺曲线落到底部，不再竖直截断。填面底部闭合但不额外画贯穿全图的底线。
- 根据实施期间的补充，深圳移除右侧长桥，以市民中心屋檐结束。保留楼群顺序与主要高低关系，立面线条按结构整理，建筑间隙和市民中心开口保持白瓷。
- 各单元分别保存填面、线条与孔洞；组合显式遮挡后方线条。母版仍为 5433×2365，运行通道 4096×1783，原 UV 放置只应用一次。
- 两城已接入本地 V5。材质代码与 UI 契约未变：五色预设、HSL、固定金线、连续彩釉/金属滑杆、0–2 倍法线强度继续使用原实现。
- 更新原有素材复核页，提供白底线稿、灰色填面、金线填色与单元链接。原稿、旧版生成稿和原 PSD 均保留。

- 使用内置 ImageGen（未使用 API/CLI）分别产生两张研究稿，完整提示词与原文件在 `assets/source/v5/rebuild/`。北京仍有右端截断，深圳仍有边缘残留，因此均未直接当作最终图样接入。
