# 完成记录

## 实际改动

V7 更新为 7.0.2，基于上一阶段源码 `922fad6` 与发布归档 checkpoint `b47a163`。资源版本仍为 v7-1，195 份资产内容不变。

加载页直接存在于初始 HTML 中，沿用柔光背景和透明文字信息布局。统计当前作品首屏材质的所需字节、已读取字节、读取速度、耗时与完成项数；首屏深圳 13 项共 2,286,310 字节（约 2.18 MiB）。数据来自读取流，不用定时器模拟百分比；不把全部城市或后续高清资源算进首屏。图形资源/预算标注为应用估算；JS 内存只读取浏览器提供的值，WebKit 不提供时明确显示。

下载 100% 与进入设计分开判断：背景、全部必需纹理、城市及反射均准备好，并且实际绘制了完整场景，才淡入设计。此前设计区保持不可见、inert，不提前显示空杯。缺失资源会留在加载页并显示重新加载入口；进入动画被上下文丢失打断时取消旧的进入回调，恢复后重新等待完整画面。

线上 7.0.1 WebKit 停等的诊断证据为：文档 visible、网络请求已完成、解码队列保留一项且无回复。图片改用文档内图像解码和串行通道提取，保持原先的纹理方向；RGBA 色彩图通过 GPU 翻转，R8/RG8 遮罩在读取时翻转。高精度法线仍在 Worker 校验和解压，15 秒未回复会重建 Worker 并最多重试一次；保留取消、失败保留当前款式及原有内存预算。没有降低法线精度或移除两类反射。
