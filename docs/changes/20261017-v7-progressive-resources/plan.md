# V7 最终执行计划

完整需求、批准的行为与验收计划见同目录 request.md「执行请求与修订后的计划」，该节为本计划组成部分。

采用用户最后修订的范围：优化当前前端与资源组织，以可运行 mock 和独立联调页演示保存、还原、分享；不实现公司正式账号或生产数据库。账号隔离等仅在明确标示的本地 mock 中演示。保留反射、金线、字形、现有颜色和触感控件。

1. 基线 a231937（V6.0.1），独立 codex/v7-progressive-resources 分支。先生成分级贴图及版本清单：1024/2048/4096、分区护边、合并 ORM、裁切 R8 文字、RG8 城市遮罩、高精度半浮点法线，保留全部原稿与哈希。
2. 用 bootstrap/manifest 驱动消费者资源；两个资源任务、单 Worker 解码、过期任务取消、按字节缓存；原子切换并保留失败前画面。近看停止操作 300ms 后提升当前部件清晰度，移动最高 standard；主画面按帧耗时动态 DPR，静止/后台停止重复绘制，处理上下文恢复。
3. 消费者、开发审计、联调样例分离构建。保留窗口调试能力并新增作品导出/还原/订阅；静态 bootstrap JSON 可直接托管，HTTP mock 可替换同一契约，支持资源/CDN 和应用子路径配置。
4. 交付 OpenAPI、JSON Schema、数据关系、Node mock、独立联调页、CDN 配置与本地部署说明。示例账号非正式身份，不保存真实用户数据。
5. 跑现有单元测试、资产尺寸/哈希/法线/裁切对齐检查、Chrome 与 WebKit 浏览器回归、资源预算/冷加载/快速切换/近看/暂停/恢复/导入导出/mock 契约检查；记录实际数字与未达目标。iPhone 13 mini iOS18 30分钟、实体触感与设备帧率仍须真实设备验收。

初始 GPU 预算：首屏贴图 64 MiB，移动常态纹理加渲染目标 128 MiB，切换峰值192 MiB；预算不是系统内存上限。冷缓存10Mbps/100ms目标5MiB/6秒；保留反射，达不到时如实记录，不降低约束掩盖失败。

完成记录随每个 checkpoint 更新；不 push、不部署、不创建 PR，不修改 V6 发布归档。制作前检查空间，缓存与构建写项目 .codex-work。
