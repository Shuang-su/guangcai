1. 在现有 `codex/source-consolidation` 工作树确认分支、upstream、干净状态及容量；保留其他产品分支。
2. 保留附件旧路径及历史检查结果，追加用户确认、保留版本或停止追查的状态。对19份保留文件计算SHA-256，与既有归档对象实际字节比较。
3. 盘点初号機广彩目录内的普通文件，以长度筛选，再以SHA-256确认相同内容；不跟随符号链接，不读取凭据或Git内部对象参与普通文件查重。
4. 将原件内部重复、原件与工程引用、历史工程、运行资源、构建及部署暂存分别说明。统计逻辑字节与实际分配空间，避免把ExFAT分配量或所有重复都当作可释放容量。
5. 保存完整重复组和构建目录逐文件匹配结果；只提供可复核清单，不删除重复副本，不把未匹配展开文件当作未归档。
6. 同步当前README、位置说明和来源索引状态，保留此前完成记录的时间边界。验证JSON统计、文件哈希与链接，提交并推送现有PR，回读远端。
