# 迁移方案

1. 盘点Prism广彩目录、Git状态与共享工作树关系；按初号機ExFAT实际分配单位估算空间。新主仓库采用`/Volumes/Prism_初号機/广彩/guangcai-main`，不覆盖已有目录。
2. 复制独立main仓库，逐文件核对SHA-256、符号链接和Git连通性，保存来源清单、扩展属性及必要的ExFAT适配记录。
3. 将旧V7工作树、独立V7.1.2副本和Prism本地恢复目录分别压缩归档；保存文件级清单及扩展属性，逐成员解包流校验，再复查源文件。仅排除明确可再生的node_modules。
4. 删除前再次核对进程占用、源/归档哈希、目标main的独立Git及当前状态。注销已归档的旧V7关联工作树、移除其合并分支，按精确清单删除Prism源目录。
5. 稳定入口`guangcai-repo`切至新主仓库，同步README、工作区说明和本机入口文档，保留恢复步骤。提交、推送并合并记录，最后新目录回到与远端相同的main，删除本轮临时分支。
