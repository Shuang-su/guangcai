# 最终计划

1. 使用内置 ImageGen，以原北京/深圳和 PSD 为细节参考，保留建筑曲线、窗格、屋檐、栏杆；深圳仅去右桥，北京单独修正长城收尾。
2. 使用干净白底原稿，提取结构线；独立创建填色边界与语义孔洞。辅助闭合只用于填面，不进入可见金线/法线。SVG 只作原稿轮廓提取，不程序化重构地标。
3. 增加与源图绑定的视觉审查记录、细线保留度与像素/填面检查，生成同一套 4096×1783 运行通道；更新素材复核页。
4. 建立可复用流水线：源稿哈希/审查 → 编译 → 素材/应用测试 → 构建 → 本地浏览器测试 → 独立 V5 部署 → 服务端文件回读 → 在线浏览器复测。任一阶段失败不继续发布。
5. 独立站 `guangcai-no1-china-v5`，明确禁止对 V4/V3/原版目标发布，不建立 Git 自动部署绑定。凭据只在进程内读取已有 Netlify 登录，绝不写入记录/缓存/源码。
6. 保存失败探索、来源、验证、完整部署快照与本地 checkpoint；最后核对旧站点当前部署未改变。
