原稿文件全部保留；`assets/masters/v5/full-fill-revision.json` 保存此前配置、替换映射和 171 个保护文件摘要，验证每套图的线条、法线、高度、文字与对应来源一致，以及最新前端代码保持一致。天津／青岛的对应基线是 V5.2 新稿；版本文字同步为 5.3。旧 source manifest 是历史快照，新一轮按用户授权的修订清单验证，不改写旧来源。
