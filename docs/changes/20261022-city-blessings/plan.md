# V7.1.13 固定祝福语与长城市名本地试排

## 最终有效范围

保留原有六句与其原始资源，新增满城好运、快乐满杯、彩运连连、一路生花、彩气满满和统一 `love-city` 选项。默认深圳／我爱深圳。面板顺序为我爱当前城市、五句新祝福语、原六句；选中城市祝福语后切城更新文字，固定祝福语切城保持。保存作品保留原选择，恢复默认回到最新默认作品。

## 排版与素材

- 四字：字体66，外框127×423，原文案坐标、UV和原框不变。
- 五字（哈尔滨、石家庄、景德镇）：字体64，外框127×480，框顶从190移至133，框底保持613；五字基线258/328/398/468/538。
- 六字（乌鲁木齐、呼和浩特）：字体62，外框127×536，框顶从190移至77，框底保持613；六字基线198/266/334/402/470/538。
- 所有字形等比缩放，沿原水平中心排布。外框按顶部80／中间263／底部80切片，只延长直边；上下装饰、宽度和线宽保留。框底至杯底距离不变。
- 固定已批准字体SHA和当前MasterGo框来源，离线生成28张新蒙版（5通用＋23城市），继续单通道WebP。浏览器不加载字体。
