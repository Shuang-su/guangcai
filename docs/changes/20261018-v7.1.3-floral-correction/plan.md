# V7.1.3：按手机实拍修正花纹方向、底边与金底空洞

## 依据与目标

使用素材原件/一号杯 IMG_1159.jpg（侧边与把手）、IMG_1164.jpg（上连接处）、IMG_1142.jpg（杯碟），一号杯2 IMG_1227.jpg（下连接件、底边）、IMG_1221.jpg（杯碟近照）。EXIF 为 iPhone 13 mini。与原花纸、本轮四张标注截图共同核对。只补两个贴图白洞，保留实体白瓷连接件、城市、祝福语、配色与既有反射。

## 实现

- 侧花纹材质从局部高度 2.8 mm 向下延伸至城市的 0.12 mm；顶部与横向宽度不变。完整花纹重新映射到新范围，不复制末行像素。杯足与底面保留原材质。
- 从原稿明确标识上下两个连接孔预留区，独立可审查遮罩，不全图阈值填白。现有金底颜色与材质补面，同步颜色、ORM、高精度法线，去除白边与旧孔轮廓。保护白花瓣、蝶翅、果实高光；不改变连接件几何。生成杯身三级资源，尺寸/编码不变，保存原件、修正层与生成物哈希。
- 杯身、把手、杯碟独立花纸 UV 的所有 PBR 通道统一纠正左右方向，基础/清漆法线一起变换。杯碟镜像发生在图集分区之前，不翻整张图集。包括偏移的完整变换 u′=1−(u+offsetU)，保留实际接缝位置。法线切线基随变换后的 UV。以实拍蝴蝶、石榴籽、花叶为锚点，城市/文字独立 UV 不翻转。

固定相机检查侧面、上下连接处、杯碟两侧、拆解；保存原稿/实拍/前后对照。三级无底部白带，孔连续金底，白瓷连接件和彩绘不误改。旋转光照检查法线、图集接缝、提清不跳位。四版本往返恢复、切城/文字、上下文恢复、液态玻璃、预算回归；像素尺寸与运行时纹理数量不增加。更新 README、Issue #29、后台 Excel/JSON、来源记录，详解映射、补洞、旧版本恢复。验证后提交推送合并，部署独立 V7 并回读资源哈希、给固定链接；V6 不动；实体手机另记。构建前核算磁盘，项目缓存优先；必要时用内置临时空间，归档与远端核验后清理本轮内容。
