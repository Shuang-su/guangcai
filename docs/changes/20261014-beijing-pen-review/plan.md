1. 对照北京原PNG、中国原PSD天坛图层和被拒绝的imagegen高清候选。
2. 排除生成候选新增的檐口纹理、门窗和云纹。复核当前运行稿实际仍来自原PNG等比重采样，不把候选误称为线上运行素材。
