- 北京经内置 ImageGen 两轮候选调整。按用户后续反馈去掉前景波浪和多余山线，让央视、中国尊、天坛、长城落在共同底线；原 PSD 天坛层用作结构和细节密度参考，不宣称生成图是该图层的逐像素复制。深圳沿用用户认可的已有黑线母稿。
- 保留原 JPEG、两版北京生成 PNG、完整提示词与来源哈希。北京实际生成像素为 1899×828，深圳源稿为 1900×828；运行导出 4096×1783 不冒充原生 4K。
- 从 PSD 城市外框建立 5433×2365 SVG 模板、底线与文字预留。每城独立 lines/fill/holes 分组，SVG 为可编辑轮廓路径，非嵌入位图，非手工中心线绘制。常规编译保留已保存 SVG；明确 --trace 才从源稿重建，来源哈希改变时要求复核。
- 通过登记表统一生成城市资源和前台入口。每城共享结构遮罩、RGBA16F 法线与文字；五色预设使用统一参数，不复制五套贴图。当前登记北京、深圳，20 城名单与逐城构图尚未开展。
- 前台保留五色预设和 HSL 调色；金线固定 #dcb251 与独立金属参数；彩釉至金属连续联动金属度、粗糙度、釉层反光，浮雕为 0–2 倍法线强度。取消轻浮雕彩绘，旧 paint 输入归一到彩釉。
- 材质拖动更新 uniforms，不重建贴图、着色器或固定环境；最多缓存两个城市包。换城保留自定义参数；配色预设恢复参数。快速切换只采用最后一次完整结果，失败保留当前效果。保留中国原版接口与固定花纸、白瓷、金边、器型、相机功能。
- 增加 V5 素材审阅页，显示原图、当前北京候选、深圳母稿、原 PSD 天坛、SVG 和填面，并提供模板及两城母版下载。移动端创作面板显示五色与材质滑杆，颜色控制可继续滚动；UI 和端点值仍为本阶段初版。

## 过程中发现并处理

- 系统 Python 缺少图像依赖；复用已有 Python 3.12 的 Pillow/NumPy 与项目内 vtracer 缓存，没有全局安装或保存凭据。便携依赖清单已保存。
- 最初浏览器脚本用固定 50 ms 等待合并后的滑杆输入，在窄视口提前读状态而失败；改为等待实际材质参数达到目标，再完成全套回归。
- 初版手机配色布局沿用三列，挤压材质入口；改成五色一排、可滚动创作抽屉，并完成触摸模拟。
- 保留深圳“和合共彩／共创美好”的手选入口与跨城回退，补充回归；恢复默认款同时恢复原始浮雕强度。
- 参数化遮罩通道与旧金属观察模式不同，已更新该观察模式以显示实际联动的金属覆盖。
- 构建保留原有 650 kB 警告阈值，主 JS 包约 664.28 kB（gzip 约 173.99 kB）触发体积提示；不是构建失败，本轮没有提高阈值掩盖提示。
- 构建工具只改变历史 `evidence/web-textures.json` 的时间字段；确认其余内容一致后恢复历史记录，V5 构建结果独立保存。
