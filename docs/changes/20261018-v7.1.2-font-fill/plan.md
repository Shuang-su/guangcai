# V7.1.2：思源宋体祝福语与 23 城填色复核

## 1. 已核实的现状与本次范围

- 目前确实使用指定的“23个城市线稿”目录。23张原稿与项目制作源图逐字节一致，23条派生记录的来源哈希也一致；线上当前v7-2 manifest与本地相同。
- 23城4K遮罩已做总览与封闭空洞扫描：西安3处微小封闭空点，最大约26像素，位于右侧城墙接缝；其他22城未检出封闭空洞。这不排除与天空连通的开口漏填，后续逐处检查。
- 六组杯身祝福语统一改用思源宋体 CN Bold，字框和字距整套对齐本次SVG/MasterGo；菜单字体保持现状。
- 只修正文字样式与确认的漏填区域，保留原有描线、金线反光、花纸、配色和材质表现。

## 2. 祝福语制作与运行方式

- 使用已找到的SourceHanSerifCN-Bold.otf，内部名称思源宋体CN，字重700。字体版本、哈希、来源和许可说明纳入制作记录；失败明确报错，不使用系统字体替代。
- 保存SVG原件。文字已转路径，字框含209×694嵌入位图；分离文字与边框，按参考轮廓生成可放大矢量边框，在参考尺寸和放大尺寸叠图核验。
- 从参考四行实际包围框提取字号比例、水平居中和字心间距，应用全部六句。保留杯身整体位置与显示高度，内部排版以新参考为准。
- 构建时生成六组裁切遮罩，保留4px护边，重算uvRect。运行时R8遮罩、首屏预热、缓存纹理切换，不下载字体。
- 文字和边框沿用金色材质及反光；记录尺寸和占用，防止裁边、重叠及缓存增长。

## 3. 城市填色检查与修复规则

建立全部23城检查记录：原稿、当前遮罩、参考图、疑点坐标、判断、修复前后对照。
- 封闭空洞：检查三级，修复西安小接缝，检查缩放掩盖的小点。
- 开口漏填：自动标记候选，逐一放大，对照原稿及可匹配的杯子参考。重点屋檐/墙面连接、塔身分层、城墙、山坡、桥体和交叠区域。
- 全填规则：内部不留意外露白；外部天空、楼间开放空间、外轮廓外保持留白。禁止“某线以下全部涂满”。
- 独立可审查修正层，只增加G覆盖。各档R描线、法线文件、原始PNG不变，不重描。
- 21张参考照片逐张建立能确认的身份；缺城市对应照片时使用线稿和全填规则，不编造对应。
