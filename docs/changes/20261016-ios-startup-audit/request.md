# 用户反馈（按发生顺序）

1. 切换不同调色板后的震动启动有延迟。
2. “买葱一斤恢复”，随后澄清：“脉冲已经可以了”。
3. 对发生位置的补充：“切换和点击完色相饱和度与明度切换都有”。
4. 启动都有延迟。
5. 针对之前“修正控件放大后的坐标。色盘按下时会放大、移动，现在同步换算触摸位置”的说明，批注：“我的放大动效被去掉了”。
6. 快速拖动时不响应。
7. 对不响应的补充：“只有震动没跟上，数值正常变化”。
8. 应该还是启动延时的问题。

此前报告设备为 iPhone Air／Safari 27.0.1，以及 iPhone 16 标准版／Safari 26.6.1。此次确认连续脉冲可用，没有分别给出每台设备的时间测量。
