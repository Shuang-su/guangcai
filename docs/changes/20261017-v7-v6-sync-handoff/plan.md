# V7：跟进 V6.0.4、完成体验验收与开发交接

## 1. 基线与最终体验

以 V7.0.4 为基础，接入 V6.0.4 的液态玻璃、面板收起修正和持续下载保护，形成 V7.1.0 候选版本；先完成体验验收，再确认开发交付完成。

V7 基线 ea48236（应用源码 9d3a6f4）；V6 功能基线 833a8b3，发布归档 5a2d7e4。整合相关源码、测试与说明，避免引入旧资源加载方式及整套归档。在 Prism 的现有工作区建立 codex/v7-v6-sync-handoff，V6 工作区和线上站点不动。

默认保留液态折射，资源预算不足或持续帧耗超标回退磨砂。Safari 不提供内存接口不直接降级。iPhone Air / iOS27.0.1、iPad mini6 / iPadOS16.6.1 的 V6 真机反馈作为视觉基线，不代替 V7 性能验收。进入前保留所有城市低清、当前及相邻高清、固定花纸、六组文字，完整画面准备好再进入。

## 2. 液态玻璃与性能整合

保留 V6 独立 WebGL2 合成、材质参数、形变、收起锚点、杯壁及杯盖反射与触感。V7 preserveDrawingBuffer=false；实际模型绘制后同步上传模型纹理，UI 动画复用纹理；每帧最多一次玻璃合成，静止停止、后台暂停。

统一估算多个 WebGL 上下文中的玻璃贴图、帧缓冲、材质图生成和临时缓冲，CPU 解码缓存分开记录。手机常态 128MiB、峰值192MiB；分配前释放闲置，拒绝非必要高清，仍不满足则磨砂并释放液态资源。主画面 DPR 允许在1–2调整。deviceMemory 仅粗略提示；不得显示系统剩余内存。

仅统计前台连续交互/动画；排除初次编译、网络和静止等待。连续两个2秒窗口的帧间隔 P95 >33.3ms 触发磨砂；预算不足、初始化或上下文失败立即回退；本次会话不反复切回液态。

## 3. 下载、城市与文字

资源请求使用120秒无进度超时；请求开始计时、非空数据重置，排队不计时。保留外部取消、两项网络并发、单项解码、单缓冲读取、长度/哈希和 Worker 解压。用户取消不重试，临时网络/408/429/5xx最多三次；无效格式、哈希、404直接报错。

加载失败保留完成缓存并允许重试，不虚报100%或露出空杯。前后台恢复不能误判挂起时间。23城低清缓存但仅当前解码上传，临近高清有优先级，过期任务取消。六组裁切 R8 文字预热，只切纹理引用与参数，不重新绘制4K、不触发无关反射。

Netlify 公网延迟仅记录，重点验证下载量、重复请求、解码、切换。正式COS链路待公司地址可用后联调。

## 4. 开发接入与交付

复用 DesignConfig、ResourceManifest、v7-1、模拟服务。设备策略不保存到作品，资源未变不重新编译。cupViewer 保留原API，增加可取消 whenReady({signal})、getLoadState/onLoadStateChange，包含阶段、字节、最近进度、错误，移除联调样例60秒总等待。

模拟服务增加精确开发Origin白名单和OPTIONS，验证前端/API/资源三地址及子路径；保留账号隔离、幂等、修订冲突、分享快照/撤销，模拟登录不用于生产。COS需版本URL、缓存、CORS/MIME/Timing-Allow-Origin；HFN原始字节、无Content-Encoding:gzip、不改写数据WebP。

交付消费者静态构建、独立样例/mock、OpenAPI、JSON Schema、作品、数据关系、账号映射、资源哈希/目录、部署配置、验收记录。正式身份/数据库/业务后端由公司程序员映射。母版及历史保留原位并提供索引，不复制进消费者包。

## 5. 验证、预览、完成条件

验证下载持续/停滞/取消/缺失/乱序/长度/哈希；23城6文字快切/高清参数不变；静止杯子+面板动画折射；展开收起旋转拆解/回退；多轮预算和上下文恢复；导出还原、账号隔离/过期、并发409、幂等、匿名分享、撤销及历史版本回放。

10Mbps/100ms RTT冷缓存3轮，完整进入目标每轮≤15秒，记录实际量和分段耗时，失败保留未通过。Air和mini6对照V6折射及菜单；iPhone13mini/iOS18连续30分钟覆盖全部流程，无重载白屏或不可恢复丢失，目标30fps。自动化与真机分别记录，未收到反馈不得标体验通过。

按功能整合、预算/加载回归、接入交付三阶段checkpoint。每阶段提交请求/计划/完成记录与SHA。容量检查，缓存暂存.codex-work；有需要使用本轮专用内置盘暂存并在完成后删除。仅更新独立V7 Netlify预览，提供固定部署链接，回读版本/哈希；正式COS联调/生产发布在后续阶段。
