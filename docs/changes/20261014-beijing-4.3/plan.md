# 中国杯 4.3：新增北京主题与五款配色

## 方案确认
线稿作为北京主题的制作依据，由同一份线稿制作填色范围、金属区域和凹凸，再套用现有中国款的配色及材质。保留祈年殿、长城、山峦和云纹，不额外添加花鸟，也不重新生成建筑。新增北京纯金、青绿金线、红金、紫金、蓝金五款，版本 4.3 / 4.3.0。

## 素材与凹凸制作
- 保存原始透明 PNG 及来源哈希。源图 1942×810，清理孤立杂点、检查断线，建立五款共用线条母版。
- 按现有杯身展开规范输出4096×1783通道。保持比例与构图，统一缩放、底部定位、左右安全留白，不直接拉伸。用户追加要求尝试原图超分；生成结果须与原稿叠图，不得以虚构细节替换建筑。
- 分开制作建筑、山体封闭填色遮罩与线条高度；覆盖屋顶、墙面、栏杆、台阶。天空白瓷留白，云纹描线；不能简单填洞导致开放区域灌色。
- 五款共享结构定位、高度；颜色、覆盖、金属、粗糙度、法线独立且对齐。高度母版16位，运行法线高精度。
- 凹凸来自结构线与轮廓，不从彩色亮暗提取。无图案区域平坦。

## 款式、文字与前台接入
- 北京纯金沿用中国纯金参数，固定效果；青绿金线、红金、紫金、蓝金复用中国配色，可选彩釉金线、彩色金属、轻浮雕彩绘。
- 新增北京入口与五款缩略图，进入北京默认纯金，彩色款默认彩釉金线。
- 北京“随款式”和“主题名称”均显示北京 / BEIJING，文字随配色，纯金文字为金色。隐藏跨主题保留，深圳专属标语到北京回随款式。
- 原稿牌匾“祈年殿”为建筑细节，不随主题文字开关隐藏。
- 扩展主题目录、默认款、材质能力，去除仅中国/深圳判断。兼容applyCityArtwork(pack)和选择状态接口。
