# 有效修订计划

1. 去掉不透明卡片底板，使用有厚度的倒角边、微凸玻璃面与图案颜料层。真正启用透射/折射、IOR、厚度与颜色衰减。原生 HTML radio、名称、单选状态和按钮保留。
2. 新建可被玻璃采样的 GPU 水气背景，使琉璃透射有实际背景内容。杯子保持独立中性照明。背景加入青蓝水气、淡紫与暖色折光、水岸影像和轻微流动。
3. 将同轨双层绕框改为四条不同曲线的开放式飘带，独立宽度、扭转、拱面、收尖。换组用五层曲面自左向右依次扫过，在重叠遮挡时切换选项；返回也遵守用户明确的左向右方向。
4. 首页/结果的远景、水墨前景与纸张按不同速度响应页面切换，保留减少动态效果设置。创作水气背景淡入/淡出，不以整杯闪烁实现转场。
5. 对照已保存的 Hey! 参考，使用同一滑动进度驱动光丝交织、收圆、与真实杯口投影对齐、俯视转正、独立杯盖/碟子组入场。末尾浮现自有水墨背景和既有主标题，支持回看和跳过。
6. 成果 3D 横向铺满，投影扩展至整屏，取消内部视口硬裁切；限制过近观察距离。海报离屏导出保持独立。
7. 内置 image_gen 制作无字、透明底水墨按钮，保留母版与提示词，生成运行 WebP，替换相关水墨页面主按钮。
8. 以实际渲染、操作录屏、关键帧和异常回归为证据。维持纯图案只作为选项，五步不影响杯体，最后仍统一呈现固定花蝶·金地。真实手机性能另行验收。
