# 实际验证报告

验证日期：2026-09-21。运行于本机 macOS / Apple M1 Pro；Chromium 使用已安装的 Chrome，WebKit 使用 Playwright WebKit。下列结果来自实际浏览器及生成的几何数据，不是依据代码存在推断。

## 已通过的检查

- 类型检查与 Vite 生产构建通过；生产输出不包含常驻界面或开发参数面板。
- 15 项几何与换款自动测试通过：闭合边、非退化面、有限单位法线、整体有向体积、真实 D 截面、几何波纹、装饰 UV 范围、两档 UV 锚点、无效参数、抽样最小壁厚、加载失败释放、并发最后请求胜出。
- 抽查 5 个杯高截面，最小壁厚大于 2.35 mm；默认名义壁厚 2.6 mm。此值是模型数据检查，不是实物测量，也不构成任意参数组合下的全局曲面自相交证明。
- chromium：21 项浏览器流程全部通过，无非预期控制台错误。
- webkit：21 项浏览器流程全部通过，无非预期控制台错误。
- 另有 5 项触控、长按、横竖屏、手机模拟帧时间与无 WebGL 提示验证通过。Chromium 的拖动与双指捏合使用浏览器原生触控输入事件。
- 两种引擎都实际加载生产 dist 并完成换款、翻底、复位；减少动态效果下杯体最低点仍离台面约 13.0 mm。生产环境拒绝开发检查接口。
- 首次只显示当前款式；完整纹理组载入后统一替换；8 次重复换款中 geometry 对象 ID 不变，稳定渲染时资源计数保持 19 个 geometry、11 个 GPU texture。dispose 后 geometry 计数为 0。统计是 Three.js 资源计数，不等同于显存字节数或长时间堆内存泄漏证明。
- 静止 500 ms 前后帧计数不变。动画、轨道阻尼、加载完成和视口改变会主动请求重绘。
- 依赖审计当前为 0 项已知漏洞，详见 dependency-audit.json。

## 实测帧间隔

先预热再采样约 120 帧，移动相机持续重绘。下表为本次测试条件下的帧间隔，不代表首次编译时间或实体手机指标。

| 场景 | P50 | P95 | 说明 |
| --- | ---: | ---: | --- |
| chromium 1440×900 | 16.7 ms | 17.5 ms | 同引擎空白页 rAF P50 16.7 ms |
| webkit 1440×900 | 33.0 ms | 37.0 ms | 同引擎空白页 rAF P50 33.0 ms |
| Chromium 390×844 手机模拟 | 16.7 ms | 18.4 ms | low 贴图，像素比 1.7，反射 512 |

Chromium 本机交互接近 60 帧。WebKit 本次自动化环境约 30 帧，空白页也约 30 Hz，因此不能把全部差异归因于模型负载；这是对对照样本的推断。WebKit 触发了低档质量：像素比 1.1、反射 384。真实 Safari、实体 iPhone/Android 尚未做性能验收，不能宣称全设备达到 60 FPS。

## 视觉和设备证据

- 两款均保存了整套、正面、把手侧、开盖俯视、底部与把手/波纹近景。白底款保留金地碟带。
- 分别检查 1440×900、1920×1080、390×844、430×932、844×390。移动截图为 device scale factor 2 的浏览器模拟；几何采用 medium，波纹、圆角、壁厚、凹底仍存在。
- 实际转动观察时白瓷软箱高光、金彩明暗与倒影会变化；内壁与白瓷留白无彩绘。侧面近景与法线检查显示波纹是连续顶点起伏。
- UI 手势包含桌面鼠标、移动点选、拖动误点、多指误点、快速换款、缺图回退、动画中换状态、翻底复位、键盘与临时帮助。
- 影像是浏览器直接截图，没有后期替换器物或绘制伪造倒影。

## 贴图对齐检查

- 两张母版 SHA-256 与最初生成版本一致。high/low 尺寸、KTX2 文件头及所有材质资源存在性通过。
- 以高度内容边缘检查 normal 响应：杯身约 99.37%，装饰带约 99.88%；杯身金属遮罩与母版覆盖边缘的平均偏差约 0.0027（0–1 范围）。这检查坐标和边缘一致性，不证明每条金线的语义标注都准确。
- `body-alignment.png` / `band-alignment.png` 从左至右为彩色与浮雕边缘叠加、金属遮罩、高度，全部来自相同像素坐标。
- 棋盘格证据与真实装饰边界模板在 evidence/ 与 assets/uv/。
- chromium 同一取景下 KTX2 与 PNG 回退的器物区域平均通道差为 0.542/255；未出现垂直翻转或换位。
- webkit 同一取景下 KTX2 与 PNG 回退的器物区域平均通道差为 0.651/255；未出现垂直翻转或换位。

## 明确保留的边界

1. 尺寸、盖底定位、凹底内部结构与接触足表面均包含推定，不是工业测量或可制造 CAD。把手与杯身用闭合曲面重叠连接，未做 CAD 布尔融合。
2. 花纸是生成重建，背面延展与金线语义遮罩有近似；母版原生分辨率已如实标注，未将放大图称作原生 4K。
3. WebGL PBR 和实时平面反射已验证；多层釉的真实光谱、离线路径追踪、实体手机性能及长时压力测试未验证。
4. 原 Documents 工作区发生 iCloud dataless 文件与读取停滞。工作副本转至 /Volumes/Prism/GuangcaiCeramic，原目录和其他未跟踪工作保留；没有发布线上服务。
