## 五步内容

1. 为开放添一线：向海而开、海路交汇、星湾相连、潮汐相拥。
2. 为创新添一形：繁花盛放、百鸟和鸣、蝶舞新生、花鸟相生。
3. 为合作添一重：交织、相映、共簇、接力。
4. 为繁荣添一彩：海纳蓝、焕新紫、同心金、共融绿、繁盛红。
5. 为未来添一愿：山海相连、新意共生、携手同行、共赴繁荣。不开放自由文本。

选择完成后统一使用花蝶·金地。成果文案必须明确「数字款式示意」「与五步选择暂未关联」。只有确认重新体验才清空草稿和结果。

## 实现与视觉

复用原一号杯真实杯 / 盖 / 把手 / 碟几何与装饰区，原观察器保持独立、不修改。Vite + TypeScript + Three.js，抽离 CupViewer 生命周期、相机 / 手势、原子材质与实际截图。开场不提前加载 3D，结果前不加载花纸材质。生产运行时不含其他两套款式。

开场采用二维分层 + SVG 线条路径 + 实际模型导出的白瓷图，不假称视差层是真实空间扫描。微光、线条、远景、杯子以不同位移速率响应滚动；可反向回看，不加入按住、打分等游戏机制。

琉璃彩带是带透明通道的二维装饰图，单独 CSS 图层；允许做位移、轻微压缩、扫光，pointer-events:none，不参与杯子照明、不拦截手势。不承诺真实玻璃折射、布料模拟、任意视角丝带几何。画面主要标题用金色宋体栈，正文深蓝灰，按钮为实际 HTML / CSS 绸缎与水墨样式。

二维母版、SVG / CSS 动效、海报排版代码可编辑。Image Gen 仅制作装饰资产及方向参考；参考图中的杯型、已着色创作杯、错误步骤标记都不得替代功能基线。无字形授权文件时使用系统宋体，不声称与参考海报字体完全一致。

## 本地演示与接入

localStorage 存五步，IndexedDB 存海报 / 杯子 Blob。存储不可用时当前会话可继续，并提示无法持久保存。RemoteActivityPort 仅定义配置 / 作品 / 榜单 / 公开 / 分享归因 / 奖项边界，不假造真实远端；GaussianModule 定义加载、就绪、错误、退出和释放，格式待定。详细数据例子见 `docs/integration.md`。

## 验证与交付

顺序：基线与状态 → 真实观察器及海报 → 分层视觉与视差 → 全路径和本地恢复 → 接口 / 资产 / 证据归档。功能、像素与资源检查各自独立，不能以构建通过代替浏览器效果或手机性能。

- 单元检查：草稿恢复 / 选项合法性 / 路由，1,280 种组合固定款式。
- 浏览器检查：真实旋转 / 双指缩放、返回 / 刷新 / 分享落地 / 重开、海报 img 与同款版本、无 3DGS 请求。
- 故障注入：开场超时、贴图缺失、海报失败、WebGL 不可用 / 中断、存储受限；各自提供恢复路径。
- 视觉检查：360 / 390 / 430 手机视口与 1280 桌面；金色标题、水墨底、绸缎按钮、透明彩带与 3D 可读性；截图与多视角操作录像。
- 性能：先设置 DPR / 阴影 / 贴图边界并记录本机浏览器实测。真实 iOS / Android / 微信设备、长按保存及稳定约 30 fps 仍须真机测试，明确标为未完成项。
- 交付：完整源码目录、README、原资产及运行时清单、接口说明、有效计划、检查 JSON、截图 / 录像、完成记录。无 Git 的项目不初始化仓库，说明无 checkpoint SHA。未部署。
