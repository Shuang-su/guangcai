# 器型参数与 UV 合约

单位为 mm；场景换算为 100 mm = 1 Three.js 单位。`src/geometry/parameters.ts` 是唯一默认参数来源，`validateParams()` 拒绝明显越界值。照片没有标尺与相机标定，除 151 mm 杯碟标注外，下表均为建模推定，不能视作产品测量。

| 参数 | 默认 | 依据/用途 |
| --- | ---: | --- |
| height | 112 | 正立图杯身比例 |
| radiusTop / radiusBottom | 42.5 / 41.8 | 轻微收分，推定 |
| flatCutDepth / flatTransitionRadius | 9.5 / 4 | IMG_0964 杯口、IMG_0959 平面与弧面过渡 |
| wallThickness / lipRadius | 2.6 / 1.1 | 口沿及内壁推定，不是量测 |
| bottomThickness / bottomRecessDepth | 5 / 1.7 | 横放图只支持有凹底；内部厚度不可见 |
| fluteCount / fluteDepth / fluteEdgeFade | 16 / 0.18 / 0.12 | 真实顶点起伏；深度是正负振幅，边缘衰减为归一化宽度 |
| handleReach / handleWidth / handleThickness | 31 / 10.5 / 4.6 | 扁宽带状把手，沿长度扫掠圆角矩形 |
| handleTop / handleBottom | 94 / 29 | 相对于杯体底面的连接高度 |
| lidRadius / lidThickness | 44.6 / 3.6 | 独立圆形盖；下方圆形定位环缩至可进入 D 形杯口 |
| knobHeight / knobSpan | 15 / 28 | 拱形带状盖钮，局部细纹 0.12 mm 推定 |
| saucerRadius / saucerHeight | 75.5 / 13 | 直径 151 mm 为图中文字，边高为推定 |
| innerFloorRadius / footInset / footWidth | 3 / 2 / 1 | 内底圆角、足部收进与接触宽度，均推定 |
| fluteRootHeightFade / fluteRootWidthFade | 4 / 8 | 根部波纹衰减尺度 |
| handleRootFlare / handleRootBlend | 0.4 / 32 | 根部加宽比例与归一化衰减参数 |
| knobWidth / knobThickness / knobFluteDepth / knobFluteCount | 7 / 3.5 / 0.12 / 18 | 盖钮宽厚、细纹幅度与数量 |
| lidLocatorDepth / lidLocatorWall | 2 / 2 | 定位环深度与壁宽 |
| quality | high / medium | 两档共用截面和 UV 定义；手机默认 medium |

430 ml 仅作为参考文字保留，本项目没有以容量倒推内部测量尺寸，也没有声称模型容量为 430 ml。波纹间距由切平有效宽度与 fluteCount 决定，避免数量、间距互相矛盾；可改 cutDepth、过渡半径或数量调整间距。根部波纹衰减范围在参数表以 4 mm 高度、8 mm 半宽设置，可按新参考进一步校准。

器身是闭合放样曲面：外足—外壁—圆润口沿—内壁—内底—下底—凹底—足面。内外壁使用不同截面，内壁不复制外侧波纹。杯底未伪造品牌标识。把手与杯身是分别闭合并互相埋入的曲面，根部展宽与圆角提供连续视觉过渡；这不是用于生产的布尔融合 CAD 实体。

盖与碟采用独立圆形剖面回转。盖钮使用同一带状扫掠定义的拱形曲线。足面暂按较粗糙、非金属的接触表面处理；实际是否露胎无法从现有图片确定。

## UV v1

合约标识固定为 `guangcai-v1`。改变质量或款式不改变图案基准。切平面和相切圆角都属于白瓷区，不接收杯身彩绘。

- 杯身：从 +Z 侧弧/白瓷交界开始，沿大圆弧至 −Z 交界，U = 本圈弧长 / 本圈总弧长。V = y / height，0 为杯底，1 为杯口。每圈主体为圆弧，按角度均分即精确的弧长均分；两端接入白瓷圆角。上下口轻微收分不会改变花纸位置。
- 把手：U = 归一化扫掠路径长度，V = 圆角矩形截面的局部面坐标。外宽带使用独立装饰材质、两侧金边、内侧白瓷。默认装饰带 U 重复 1.8 次。
- 杯碟：U = 圆周弧长 / 周长，V = (y−3)/10。外侧装饰剖面使用独立材质，默认 U 重复 8 次。单张母版边缘经过周期混合，避免周向接缝。
- 模板与编号检查图在 `assets/uv/`；运行开发服务并访问 `?debug` 可打开 UV、法线和中性环境检查。

材质区域边界的顶点位置相同，缝两侧法线焊接。UV 接缝保留独立顶点，避免图案被错误插值。KTX2 使用 lower-left UV 方向，与 PNG/WebP 回退图保持一致。把手和碟即使使用同一母版，也拥有独立 Texture 实例与纹理变换。
