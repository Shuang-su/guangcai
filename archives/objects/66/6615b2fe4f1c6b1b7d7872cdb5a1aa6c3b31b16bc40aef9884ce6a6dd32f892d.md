# 为 APEC 添彩 · H5 首期前端

这是可运行、可编辑的本地前端演示。开场随滚动推进，创作区使用真实 Three.js 几何；五步选择只保存意愿，固定成果采用「花蝶·金地」。后端与 3DGS 尚未接入。

## 运行

本次环境为 macOS Apple Silicon、Node 26.3.0。使用项目锁文件安装。

```sh
npm ci
npm run dev
```

默认地址 `http://127.0.0.1:5177/`。项目通过 hash 路由运行，可放在子目录。生产文件由 `npm run build` 输出到 `dist/`。本轮未部署。

若在当前 Apple Silicon 环境遇到 npm 可选依赖误选 x64，使用：

```sh
npm ci --include=optional --cpu=arm64 --os=darwin --cache ../.codex-work/cache/npm --no-audit --no-fund
```

## 复核

```sh
npm test
npm run assets:verify
npm run build
```

浏览器回归使用独立无头 Chrome，不读取个人浏览器配置。先启动 dev server，再运行：

```sh
PLAYWRIGHT_BROWSERS_PATH=../.codex-work/cache/playwright npx playwright install ffmpeg
PLAYWRIGHT_BROWSERS_PATH=../.codex-work/cache/playwright npm run qa
node tools/qa-continuity.mjs
```

生产包复核：另一个终端运行 `npm run preview -- --port 5178 --strictPort`，然后运行 `QA_URL=http://127.0.0.1:5178 PLAYWRIGHT_BROWSERS_PATH=../.codex-work/cache/playwright npm run qa`。

`qa` 依赖系统 Google Chrome；其他系统可在脚本中换成自己安装的 Playwright Chromium。`evidence/` 保存操作录像、截图与检查记录。Chrome 的移动触摸仿真不能替代 iOS / Android / 微信真机验收。

## 源码导航

| 目录 | 内容 |
|---|---|
| `src/main.ts` | 页面路由、返回、异步任务与状态恢复 |
| `src/domain/activity.ts` | 五步定义、单选约束、固定成果标识 |
| `src/services/` | 本地适配层及未来后端 / 3DGS 的类型边界 |
| `src/viewer/` | 原一号杯几何、材质与 H5 观察器适配 |
| `src/media/intro.ts` | 原生滚动驱动的开场分层时间轴 |
| `src/media/poster.ts` | 实际 3D 截图与 Canvas 海报排版 |
| `src/ui/` | 原生文字、四卡单选、规则浮层、响应式与动效 |
| `assets/source/` | 三套原材质、生成装饰图母版与布局参考，不随构建发布 |
| `public/` | 运行时 PBR 贴图、20 张纯图案选项、水墨背景、实际 3D 导出的静帧 |
| `docs/` | 资产与接口说明、功能基线、视觉复核与交付记录 |
| `tools/` | 检查、实际渲染静帧及浏览器回归脚本 |

修改器型、材质或灯光后，启动开发服务器并运行 `npm run media:render`，重新导出白瓷和固定款式静帧。`media-stage.html` 是开发工作台，未加入生产构建入口。海报在用户完成五步时实时渲染，不依赖该工作台。

## 2026-09-30 连续舞台与琉璃卡片

- 新杯来自指定任务 `01a0ed06-5ea9-7532-a412-9c5a7a53716e`；11 个网格的几何、UV、索引与材质分组逐项哈希一致，见 `evidence/visual-v2/cup-geometry-comparison.json`。
- 20 张选项是纯纹样，不包含杯子，也不参与杯体上彩。当前母版与完整提示词见 `assets/source/visual-v2/pure-pattern-manifest.json`；卡面 Base Color 位于 `public/media/options/`。
- `src/viewer/glass-cards.ts`、`ribbon-stage.ts` 与 `liuli-material.ts` 使用同一渲染器、独立场景，绘制 PBR 卡片和真实曲面飘带。原生 radio 按钮负责交互与无障碍。
- 金彩、色釉与玻璃的材质区分使用 Base Color、Normal、Roughness、Metalness、Clearcoat；卡片数据贴图为同 UV 的 256×192 移动端资源。生成脚本为 `tools/build-option-maps.mjs` 和 `tools/build-liuli-maps.mjs`。
- 琉璃采用实时几何、反射、物理透射与屏幕空间折射，GPU 水气场景提供真实背景采样；材质遮罩属于艺术近似，不是实测 PBR 扫描。玻璃保持非金属，金纹使用独立遮罩。
- 主场景不为导出改变画布尺寸。海报通过离屏 HDR + ACES/sRGB 输出生成，模板版本为 `waterink-v2`。
- 本目录不是 Git 仓库，未初始化 Git；修改前快照在 `.codex-work/cache/visual-v2-backup/`。本轮未部署。
