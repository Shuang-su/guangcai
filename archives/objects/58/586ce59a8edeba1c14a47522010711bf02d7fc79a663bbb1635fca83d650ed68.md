# 最终实施计划

- 交付原生 Swift/AppKit 顶栏 App，安装在当前用户 Applications，并注册当前用户登录自启动。App 独立运行，不依赖终端、Python 或网络。
- 顶栏使用固定单图标宽度，不显示文字。异常显示红色，恢复正常自动还原；详情、暂停、阈值选择、日志、通知测试和登录自启动开关置于菜单中。
- 每 5 秒通过 libproc 读取所有当前账号可访问进程的 `ri_phys_footprint`，包含压缩内存计账；跳过退出或权限不足的进程，并显示采集覆盖数量。
- 默认连续两次达到 2 GiB 提醒，达到 4 GiB 当轮提醒，最近最多 60 秒增长至少 512 MiB 且当前至少 1 GiB 时提醒。快速增长需至少 10 秒观测；同一进程提醒间隔 5 分钟，严重程度提升立即提醒。
- 每轮合并通知，保存容量有界的本地事件日志；通知冷却不清除仍存在的红色异常状态。仅提醒，不结束任何被监控进程。
- 保留最初要求的独立 Python 脚本及双击入口作为可选方式，不默认与 App 同时运行。
- 验证阈值、增长、冷却、升级、PID 重用、进程退出、恢复、通知投递、签名和自启动注册；不分配大量内存来复现死机，不重启用户电脑测试登录。
- 后续授权：整理独立公开仓库 `Shuang-su/memory-watch-macos`，仅发布本工具代码及项目文档；使用全新历史，排除本机诊断、当前工作区其他项目与本地变更记录。发布 Apple Silicon v1.0.0 App zip 和 SHA-256 校验文件，核验 GitHub CI、公开性、远端提交及下载内容。
