# 本轮实施计划
1. 直接对照原效果图屋檐、门窗、广州塔与长城细线；检查当前材质通道和法线。
2. 保持金属底面哑光，以 PSD 原线条派生独立粗糙度权重，使线条与金属面形成柔和反射差异。
3. 对比“只分离粗糙度”和“分离粗糙度并增强圆滑线条法线”的同机位实际渲染，选取线条清晰且不会变成黑硬镜面边的参数。
4. 保留相同金属色值、金属覆盖、文字、底部定位、模型、固定广彩；不烘焙阴影、不预设建筑整面位移。
5. 更新本地生产预览及对照证据，验证切换、渲染、受保护资产和数据通道；保存完整改动记录。非 Git 项目不初始化 Git。

## 最新有效方向（取代中间候选）
用户明确选择最早较清楚的金属反射作为视觉基准。保留线条与底面的参数分离，但收回整面高粗糙度及过强线条方案；重点抬起深暗反光、提亮高光。增加杯身局部反射捕获，把真实把手／盖／碟几何纳入反射，保留关闭邻近反射的对照。局部立方体探针属于近似，不声称离线光追精度；检查材质加载、视角／拆解切换后的更新和资源释放。

## 最终参数与验收实现
- 城市包版本 3；金属底面粗糙度 0.26，线条平滑过渡到 0.22。高度核宽度 0.65 px，法线梯度 2.1，运行时 0.70，清漆覆盖 26/255，整片金属底面位移为 0。
- 杯身专用环境暗卡片 0.045、房间 0.42、大柔光源亮度乘 1.65。真实邻近几何经 512 像素 CubeCamera 与 PMREM 参与杯身反射；只在稳定的几何变化后刷新。
- 实际把手只在一次反射捕获中被暂时隐藏，最终相机画面依然保留把手；比较白瓷局部像素以确认贡献来源。对照图、开关、当前参数与历史版本分别标注。
