# 当前视觉复核

当前版本对应 `docs/changes/20260930-visual-continuity/plan.md` 及其后续覆盖项。早期带波浪杯的二维选项图、旧 SVG 细线图标、五节点进度条、静态彩带，以及过于接近 APEC 完整海报的第一批背景均不作为当前验收对象。

- **新杯**：与指定源工程的 11 个网格完全一致；正面平滑白瓷，窄花纸带在把手侧。真实操作与多角度截图保存于 `evidence/visual-v2/`。
- **选项图**：20 张均为纯图案，已人工查看总览 `options-contact-sheet.png`，无杯身/把手/盖/碟。金线、花鸟、组合、四种颜色与祝愿分别对应五步，不贴回模型。
- **卡片舞台**：PBR 开放曲面组织两行卡片，切换用约 1.5 秒的左向右五层覆盖—换组—揭开。材质已区分彩色非金属玻璃、色釉与近似金纹遮罩；HTML 保留完整操作。
- **水墨页**：首页和结果采用原山海构图、纸张、花卉与金色标题，手机/横屏素材独立；没有 APEC 海报整图、正文或标识。
- **开场**：三幕共用滚动进度；花、鸟、蝶不同贴片作错层运动，真实杯体在第三幕进入。可反向回看、跳过；减少动态效果使用分幕推进。
- **连续性**：常驻 renderer/model；规则浮层不销毁相机；导出采用离屏 render target；返回结果不重复创建成果。

`qa.json` 记录主流程、屏宽、操控与结果检查；`continuity-qa.json` 记录双指仿真、换组、恢复、旧数据迁移、贴图/导出失败及 WebGL 失败。录屏 `walkthrough.webm` 来自真实页面操作，不是动画概念片。

浏览器检查是桌面 Chrome / Codex 内置浏览器与移动视口仿真。未完成真实 iOS / Android / 微信浏览器测试，不能据此宣称真机 30 fps 或原生长按保存已验收。原生 img 长按保存能力已保留，但需要实际设备手验。

## 后续用户反馈与修订（20260930-glass-revision）

此前的材料通道和功能检查通过，不代表视觉达到用户的琉璃要求。用户指出实色底板、规整绕框、背景过干、转场方向与开场收圆缺失，本轮据此修订。

| 参考与反馈 | 实现变化 | 对照证据 |
|---|---|---|
| 琉璃卡片本身要通透 | 删除不透明底板；倒角厚边、微凸面、透射背景、颜色衰减 | `evidence/glass-revision/cards-final-430.png` |
| APEC 舒展曲面，不要双层围框 | 四条独立开放曲线，薄截面、变宽、拱面高光与扭转 | `cards-final-780.png` |
| 自左向右、多层次覆盖 | 五层玻璃面错峰进入/退出，中段换组；标题保留 | `wipe-enter.png` / `wipe-overlap.png` / `interaction.webm` |
| 背景太干、切换要视差 | 水气与弱水岸影像，远/近层错速，GPU 背景淡入淡出 | `interaction.webm` |
| Hey! 收束成圆再接杯口 | 光丝收圆与真实杯口投影对齐，俯视转正、盖碟独立入场 | `ring-430.png` / `top-view-430.png` / `assembly-430.png` |
| 成果 3D 内边距截断 | 整屏投影、横向满幅观察、动态最小距离 | `result-full-bleed.png` / `result-zoom.png` |

该版本仍需用户对最终美术风格作视觉验收；功能用例通过不替代这种判断。真实手机/微信 WebView 尚未实测。
