# 为 APEC 添彩 H5：视觉、布局与连续交互重构方案

## 一、整体方向

以已经确认的体验流程为基础，重新设计页面，不再沿用 Word 文档中的线框布局。本次覆盖首页、开场、五次添彩、成果准备、结果海报及相关辅助页面。

确立两套清晰的视觉表达：

- **首页、结果、榜单、规则等页面：** 完整采用 APEC 竖版／横版系列的水墨海报语言——宣纸、彩墨、城市山海、花卉和大幅金色标题。
- **五次添彩页面：** 以真实瓷器为主体，搭配琉璃飘带串联的 2×2 图像卡片，形成可操作的立体舞台。

杯子从开场落定、进入创作、完成上彩到查看成果保持连续。五步选择仍只记录选项，完成后统一呈现“花蝶·金地”；本次视觉重构不扩大后端或 3DGS 的实施范围。

## 二、页面布局与文案

### 首页与结果：按 APEC 系列海报重新构图

- 首页主要参考“APEC 中国年·深圳进行时”的城市、水岸与彩墨构图；结果与分享海报主要参考“当好东道主·喜迎 APEC”的三角梅、山海和纸张肌理。
- 手机使用竖版构图，宽屏使用横版构图。分别制作适配素材，避免把一张背景机械拉伸或裁切到所有设备。
- 从原图参考制作无文字的分层背景，保留鲜明的彩墨笔触、前景花卉及纸张质感。标题、按钮、导航独立排版。
- 金色标题采用接近参考海报的宋体字形、大字号和疏朗排布；固定主标题可制作精修矢量字稿，并保留可访问文本。
- 按钮采用水墨色块、纸面肌理及少量朱红印章点缀，替换当前通用的红色矩形金边按钮。非交互页面不使用琉璃飘带。
- 首页保留“开始添彩／重温开场”，结果保留“查看 3D 作品／分享给好友／再创作一件”等已确认功能，不新增宣传句。

### 创作页：器物、标题、四张卡片成为主体

手机从上到下组织为：

**轻量操作入口 → 当前步骤金色标题 → 真实杯体 → 琉璃飘带与 2×2 卡片 → 主行动按钮。**

- 撤掉顶部五节点进度条，不再重复显示通用“五次添彩”栏头。直接使用“为开放添一线”等当前步骤标题。
- 通过“上一步／下一步”返回和推进；已选内容保留，最后一步使用“完成创作”。不再额外增加步骤说明、鼓励性提示或自动保存提示。
- “活动规则”改为角落的卷轴图标入口，点击打开水墨样式的规则浮层。关闭后恢复原步骤、选择和杯体视角；图标保留完整的无障碍名称。
- 卡片使用大面积图像和原有选项名称，取消细线图标、长条列表及新增的解释句。选中反馈使用朱红印记、边缘高光和轻微抬升。
- 五步全部采用四张卡片。颜色步骤保留 **海纳蓝、同心金、共融绿、繁盛红**，移除运行界面中的“焕新紫”。
- 删除“选择仅作体验记录，暂不改变杯体与成果”“选一份心意，继续添彩”等新增文案。全站建立文案清单，以功能文档、五次添彩原稿和本次确认的流程用语为依据；实施限制放入交付说明。
- 杯体区域支持真实旋转、缩放、移动；精简常驻控制按钮，保留必要的复位和可访问操作。
- 780 像素宽的竖向窗口仍采用上下布局。只有宽屏横向窗口才切换为左侧器物、右侧卡片，避免当前过早进入桌面双栏的问题。

## 三、真实 3D、琉璃卡片与开场动画

### 杯子连续切换

当前代码在页面切换时重新挂载并复位相机，海报截图还会临时改变显示画布尺寸；这两处需要一并重构。

- 建立路由之外的常驻 3D 舞台，持续复用同一个杯体、材质和渲染器。页面变化只更新杯子的目标位置、显示区域和相机状态。
- 首页进入创作、创作进入成果时，以约 700 毫秒的过渡完成构图变化；快速连续操作从当前画面继续过渡，不先跳回默认姿态。
- 五次选择期间保持白瓷。完成后等待整套固定材质加载成功，再通过一次连续的光带过渡呈现完整款式；加载失败保留原状态并允许重试。
- 海报使用离屏渲染生成，沿用同一模型、材质、灯光与色彩处理，不改变正在显示的画布尺寸。
- 杯子先连续移动至海报中的对应位置，再由同构图的真实海报图片接管。点击“查看 3D 作品”时反向衔接；海报图片保留原生长按保存能力。
- 规则浮层、返回及步骤修改不复位杯体；“重新体验”才清空选择并回到白瓷状态。

### 琉璃飘带串联四张卡片

- 使用真实 Web3D 曲面飘带，通过曲面法线、环境反射、边缘高光和透色表现琉璃质感，替换当前横放的一条静态彩带图。
- 飘带从器物下方进入卡片区，在四张卡片之间穿行，连接两行卡片；主要沿卡片背后、边缘及间隙组织，不遮挡名称和点击区域。
- 选择卡片时，局部光泽沿飘带抵达选中卡；切换步骤时，飘带改变弧线，卡片依次更替，杯体保持连续。
- 卡片仍使用真实 HTML 图片和按钮，支持触控、键盘与读屏。飘带只承担视觉和动效，不承担不可访问的点击判定。
- 杯体与飘带共用渲染器、分别管理场景和照明，避免彩色光污染白瓷。

### 开场：三幕滑动叙事

按照你指定的三张原始分镜，融合暗场光束、纹样和彩带：

| 幕次 | 画面与运动 |
|---|---|
| **01 唤醒一束光** | 深蓝暗场中出现微光，随滑动生长为多层光丝；加入前后景粒子、雾气和景深差异，形成空间感。 |
| **02 让光抵达远方** | 视角沿光路前进，光丝展开为曲面飘带；花鸟、金线与色彩纹样在节点处逐层出现，采用错峰生长与穿行运动。 |
| **03 万彩落于白瓷** | 飘带与纹样围绕真实杯体汇聚，掠过杯口、杯身和把手；最后退出器物观察区，白瓷落定，暗场连续展开为首页的纸面水墨环境。 |

- 整段由滑动进度统一驱动，可前进、回看、快速跳过；不另加长按或拖拽小游戏。
- 纹样、雾气采用分层图像，光带和杯体采用 Web3D，分别交付可编辑素材与实现代码。
- 开场末尾保持白瓷，正式款式在五步完成后呈现。
- 文字只使用原稿中已有的内容，删除当前开场中后来补写的章节和抒情句。
- 减少动态效果模式使用分幕切换，保留相同内容和入口。

## 四、素材与实现边界

- **重新制作 20 张选项图：** 逐张以对应原稿选项为参考，保留金线、花鸟、构图层次、矿物色彩及祝愿意象；统一比例、光感与裁切，去除烘焙文字。四张卡片分别输出，不把整组概念图当成一个界面。
- **重新制作水墨页面素材：** 提供竖版、横版背景及可独立运动的纸张、城市、山海、花卉、彩墨层。参考原海报的笔触和色彩关系，不沿用当前通用山水背景。
- **补齐开场素材：** 光束、纹样贴片、雾气层、路径和时间轴均有对应运行资产；生成图片只用于二维素材，不替代杯体或飘带交互。
- **调整最小接口：** 增加常驻舞台的页面过渡、开场进度、交互开关和离屏导出接口；给海报增加模板版本，保证旧模板只在需要时重新生成。
- **兼容已有本地记录：** 保留其他步骤的选择；旧草稿若选中“焕新紫”，只清除该项并回到颜色步骤。已完成的固定款式成果继续有效，海报按新模板更新。
- 原一号杯工程保持独立；本轮修改集中于现有 H5 工程。后端身份、真实榜单、领取及 3DGS 继续按原边界待接入，不因移除说明文案而宣称能力已经完成。

## 五、实施顺序与验收

1. **先确定完整视觉稿和素材样张：** 首页、创作页、结果页，以及开场三幕关键帧同时对照原参考检查；杯体使用实际模型渲染。
2. **制作连续 3D 验证版本：** 先贯通开场落定、首页、创作、固定上彩、海报及查看 3D，解决相机复位、画布闪烁和导出干扰。
3. **完成 20 张卡片与琉璃动效：** 接入真实卡片布局、选择反馈和五步切换，再统一辅助页面。
4. **完成流程、性能和视觉复核：** 输出操作录屏、多视角截图、素材清单与变更记录。

验收以实际画面和操作为准：

- **视觉：** 首页与结果能够明确对应 APEC 水墨海报系列；创作页为四张完整图像卡片，琉璃飘带具有曲面、厚薄和流动感。
- **文案：** 逐项核对页面文本；你标出的两行、新增抒情句和重复步骤栏全部移除。
- **连续性：** 录屏逐帧检查页面衔接，无杯体消失、相机突然复位、贴图闪白或截图引发的画布缩放。
- **操作：** 四卡单选、未选择禁用推进、返回修改、规则关闭、刷新恢复、重新体验均正常；五步选择仍不改变款式。
- **成果：** 海报和成果 3D 的器型、款式及材质版本一致，返回不重复生成，图片可原生长按保存。
- **适配：** 覆盖 360、390、430、780 像素竖向窗口及宽屏横向窗口；短屏优先收缩器物区，必要时允许滚动，不裁掉卡片或按钮。
- **性能与异常：** 检查实际手机上的旋转、双指操作和转场，以约 30 fps 为初始目标；降级顺序为像素比、飘带细分和粒子数量。WebGL 不可用时提供重试／返回，贴图或导出失败保留有效状态。

本方案替代此前的页面布局与视觉方案；真实几何、固定成果、五步本地记录和后端分工等已确认边界继续有效。
