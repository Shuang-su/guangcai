# 状态、前后端及 3DGS 交接

本项目把前端演示、业务服务、资产模块分开。`src/services/local.ts` 是独立本地适配层；`src/services/contracts.ts` 仅定义未来接口。演示状态不能直接迁移为生产业务完成状态。

## 路由、状态与返回

- P00 预加载开场背景和纹样资源；不显示虚假百分比，失败显示真实重试入口。
- P01 从原视频方案调整为滚动视差。上滑推进、下滑回看，支持点击继续和跳过；没有视频播放成功的虚假状态。
- P02A / P11 合并为当前首页承接：真实白瓷常驻舞台、开始 / 查看我的作品、规则与一级导航。
- P04 同一页面五个面板。未选禁用下一步；已完成步骤可回退，刷新和规则返回保留。3D 手势仅在器物操作区域处理，页面其余区域保留自然滚动。
- P05 先原子加载固定材质，再渲染杯子与海报，成功后才建立 result 和 completed。失败保留 draft 与上一有效材质，不创建成果。
- P06 / P10 返回复用同一结果；P10 仍加载同一套版本材质，不从海报倒推模型。
- 重新体验经清空提示后删除本地草稿和成果；普通返回不会清空。
- P09 缺失详情明确报错并提供直接创作；本地编号不构造跨设备 URL。
- P12 保留榜单布局和本地作品入口，不填充虚构排名 / 获奖；P13 为演示规则浮层或独立路由。
- P14A / P14B / P15 是邮寄和现场领取页面定义：字段禁用、领取码留空，不提交真实数据。

## 后端接口接入建议

以代码中的 `RemoteActivityPort` 为类型起点，由后端决定身份、域名、接口路径与数据持久化；本轮没有假设 Cookie / OAuth / 微信身份方案。

| 操作 | 后端需提供的结果 | 前端处理要求 |
|---|---|---|
| 活动配置 | 阶段、规则版本、结果公布状态、功能开关 | 生产配置与本地演示分离 |
| createWork | 服务端唯一 ID、器型 / 款式版本、海报资源与 demo 标识 | 服务端确认成功后建立真实作品 |
| getWork | 可公开读取的作品、不可用状态 | 未公开、删除、未找到均可返回创作 |
| getRanking | 规则版本、排序字段、分页及真实记录 | 前端不得用示例序号冒充排名 |
| setPublic | 公开操作确认 | 仅请求成功后显示已公开 |
| recordReferral | 分享来源与有效归因结果 | 不把用户点击分享视作成功归因 |
| getAward | 未公布 / 未获奖 / 待领取 / 已领取等真实状态 | 校验领取规则与身份后启用真实表单 |

建议错误采用稳定的 `code`、用户可理解的 `message`、是否可重试的 `retryable`。请求取消和过期响应不得覆盖新页面。服务上线要重新验收身份、作品上传、分享可达、公开状态、榜单、奖项与领取；不能用本地演示检查替代。

## 3D 模块与资产

`CupViewer` 暴露 mount / neutral / fixed / reset / zoom / capture / pause / resume / dispose。中性白瓷与固定成果共用真实几何。固定材质的 body / handle / saucer 各有 baseColor / normal / roughness / metalness，完整读入并验证后一次应用。未用到的其他两套原材质仅归档。

未来 `GaussianModule` 暴露 load、ready / error 事件与 dispose。扫描格式和渲染器要等真实资产到位验证；首期配置 false，没有入口、下载或渲染器。不可把静态白瓷图或普通模型称作 3DGS。

## 移动端边界

像素比最高 1.5，物理材质、1K 对齐贴图、真实接触阴影，关闭方向光实时阴影；交互帧率上限约 30 fps，停止交互后按需绘制，隐藏页面暂停。真实手机仍需测：iOS Safari、微信 WebView、Android 浏览器的首次加载、手势、长按保存、内存和持续交互表现。低端档位进一步降像素比 / 贴图必须实测后启用，不把桌面仿真成绩当作手机达标。

## 连续舞台接口与最新覆盖

`CupViewer.mount(host)` 迁移观察区域而不重建模型；`setPresentation(mode, cardHost)` 选择场景；`setIntroProgress(p)` 驱动三幕；`focusPoster()` 平滑衔接标准海报构图；`capture(w,h)` 离屏导出；`ribbons.transition(swap,direction)` 在覆盖阶段执行换组。页面切换带 revision 校验，规则浮层暂停交互而不销毁相机。

颜色选择仅 blue/gold/green/red。恢复紫色旧草稿时只清除 prosperity 并回到该步骤，其他选择和已完成固定成果保留。旧海报仅按 posterTemplateVersion 重绘，ID 与业务标志不变。

选项图案只用于卡面，从不贴到杯子。最终固定材质仅写入原新杯的 body/handle/saucer 分区，杯身 bandAngle 保持原工程的 PI/3。玻璃舞台与杯体场景照明相互独立。
