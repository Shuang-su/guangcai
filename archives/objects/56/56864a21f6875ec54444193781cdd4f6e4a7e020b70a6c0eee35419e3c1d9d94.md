# 最终部署计划

1. 只读核查 Sites 与 Netlify 账号和既有站点，避免重复创建或覆盖其他项目。
2. 选择新建 Netlify 项目：已有团队可用，没有广彩项目；本项目为纯静态 Vite 多入口输出，可直接部署现有构建，不需要 Git 初始化、后台服务或密钥。Sites 新站默认私有，本次独立展示链接用 Netlify 更直接。
3. 添加构建发布目录及缓存响应头配置，保留真实缺失资源 404，不使用 SPA 全路径重写。
4. 在外置盘构建并保存不可变发布副本，使用已登录账号创建独立项目并发布生产版本。
5. 读取部署状态，访问实际 HTTPS 地址，检查三维渲染、三套贴图切换、固定材质参数、标准页、照片叠图、移动布局，以及线上关键资产与本地哈希的一致性。
6. 保存生产链接、项目与部署 ID、验证结果和更新操作方法，刷新交付说明。当前项目非 Git 仓库，不初始化、不创建 checkpoint。
