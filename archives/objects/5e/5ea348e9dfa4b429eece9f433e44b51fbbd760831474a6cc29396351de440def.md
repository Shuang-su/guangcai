# 中国杯 3.0 花纹精度与无缝修订

本记录追加于首次 3.0，不覆盖其部署档案。

## 实际变更

- 核验真实 `v1.0` 的数据：杯饰带 1024×2222、把手条 320×3119、碟花带 2172×213（四段镜像重复）。其高度/法线是 8 位 PNG；因此“回到 1.0”以恢复近看质量为目标，不恢复旧图案或四段重复。
- 发现首次 3.0 的金属分类器仍针对旧生成稿的赭黄色。原 PSD 金底与浅黄花瓣颜色不同，旧规则将部分花瓣当成金属、漏掉实际金底，造成强烈碎光。按原稿金底色重新分类，浅色花瓣保持彩釉。
- 原稿浮点高度直接求导，保存 16 位高度母版，并将运行时法线改为 RGBA16F。杯饰带 1024×2466、把手 320×3728、碟花带 8192×384。法线深浅 4.4 / 清漆法线 2.4 保持。
- 颜色与粗糙度/金属通道采用无损 WebP；法线使用 gzip 半浮点数据。总 16 张运行时贴图 26,532,672 字节，本次接受更高加载与显存成本。
- 仅在杯碟首尾 768 个原稿像素范围内生成连续花叶，128 像素肩部过渡，保留原生成结果、提示词、裁切和最终局部稿。原稿约 88.9% 横向范围未改变，杯身/把手原母版像素未变。周期边界从连续图案内部通过，各通道统一派生；不恢复四段镜像。
- 城市/文字 12 份文件逐字节与首次 3.0 相同。城市材质、结构金边、白瓷、曝光 1.08、器型、背景和交互实现未改。
- 对照页增加同机位改前/改后花瓣与接缝滑杆、灰模/关闭凹凸检查。改前取自首次 3.0 的固定部署，改后为实际 WebGL 渲染。

## 已完成的本地验证

- `npm test`：15 项通过（11 项几何、4 项半浮点格式/精度/方向）。
- `node tools/fixed-mapping-qa.mjs`：6 项通过，涵盖旧包、统一 UV、失败保留和最后一次请求生效。
- `npm run qa`：53 项通过，含城市替换、鼠标右键、双指拖移、缩放和释放；无浏览器错误。
- `node tools/floral-hq-verify.mjs`：23 项通过，含 12 份城市/文字原文件哈希、三个区域 GPU 半浮点格式与尺寸、原稿保护范围、原始 HFN1 与 gzip 两种解码路径。
- 高精度数据初次预览遇到静态服务器已解 gzip 而客户端重复解压的错误。现按魔数识别是否需要解压，两条解码路径均已验证。
- 同机位近景显示：浅色花瓣碎裂金属亮斑消除，细线与轮廓起伏保留；首尾硬切口转为连续花叶。`public/review/floral-hq` 保存原尺寸证据。

- `npm run build`：TypeScript 与 Vite 构建通过；全部 16 张运行时贴图无损核验通过。
- 本地交付检查 14 项通过：半浮点纹理、默认背景、背景切换、杯盖倒影、手机模拟、对照图解码及滑杆；无控制台/网络错误。

## 视觉与设备边界

原稿实际采样尺寸为杯饰带 637×1534、把手 148×1724、碟花带 6924×195。放大输出及更高法线精度不能生成原稿缺失的信息，极端放大仍可看到原图边缘柔软或不规则；这不是矢量重绘或实测几何浮雕。局部接缝是有明确来源记录的生成修补，不宣称原稿完全未改。

已验证 Chrome 桌面和手机模拟；未声称真实手机或 Safari 验收。现有盖钮、碟侧与离线参考的细小轮廓/高光差异保持在首次 3.0 的范围内。
