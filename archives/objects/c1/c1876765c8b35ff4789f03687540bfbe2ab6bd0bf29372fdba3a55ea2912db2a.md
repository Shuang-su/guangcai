# 国瓷永丰源「广彩传承」交互式写实 3D 展示

## 1. 交付目标与已确定方向

使用 **Vite、TypeScript、原生 Three.js** 建立完整可运行项目，首版包含**白底、金底两套广彩花纸及 PBR 材质**，桌面与手机具有相同的观察和换款能力。

默认画面只呈现器物：深酒红背景、深色台面、柔和实时倒影，完整杯盖碟组合位于画面中心，以略俯视的三分之四角度同时展示彩绘、留白波纹和把手。画面不设置常驻文字、按钮、导航或参数面板；灯光和器物默认静止，通过真实几何边缘和摄影棚反射形成清晰轮廓。

以本次提供的 8 张原图为造型依据，其中无盖图用于判断杯口和杯身，横放图用于判断底部与把手，白底、金底正立图用于校准整体比例及装饰分区。图中标注的 **151 mm 杯碟规格、430 ml 容量仅作为参考信息**；其余尺寸及不可见结构均记录为可调推定值。

第二个分享链接中的既有方案作为技术参考，在当前工作区建立独立项目，不预先继承其未经浏览器验证的完成结论。

## 2. 工程与几何建模

- 工程按 `geometry`、`materials`、`styles`、`studio`、`interactions` 分层；入口只负责组装、加载和生命周期。器型参数集中管理，记录单位、默认值及参考来源；参数调试通过开发模式进入。
- **杯身采用截面放样的自定义 BufferGeometry**：截面由主圆弧、把手侧切平面和两端相切圆角组成，沿高度控制收分与口底过渡。切平深度、过渡半径、上下口尺寸均可调整。
- **留白波纹直接改变顶点位置**：在切平基面生成连续纵向浅起伏，保留整体平面特征，在两侧过渡与把手根部平顺收束。波纹数量、间距、深度及收束范围独立配置。
- **完整建立杯体实体表面**：外壁、圆润口沿、平滑内壁、内底、外底凹陷和支承足部相互衔接。内壁独立控制，检查最小壁厚与自相交；底部标识暂不编造。
- **把手使用圆角矩形截面的带状扫掠**，还原较直的上段、弧形外段和回收下段；上下根部具有扩展、圆角和过渡曲面。花纹带、金边、白瓷内侧分别分区，根部连接在近景中保持连续。
- 杯盖、拱形盖钮、杯碟分别建模。盖和碟使用独立圆形轮廓与剖面；盖钮保留带状结构、横向细纹及金边。盖底定位结构按杯口适配，其尺寸标为推定。
- 高低细分等级使用相同参数和表面定义；手机降低细分时仍保留切平、浅波纹、圆角、壁厚及底部结构。

## 3. UV、花纸与 PBR 材质

**先确定 UV，再制作花纸。**

- 杯身彩绘区按照每圈实际表面弧长分配横向 UV，纵向按高度映射；彩绘边界止于留白区，内壁使用独立材质区。把手按带面长度与宽度展开，杯碟装饰带按周向弧长展开并处理首尾衔接。
- 固定 UV 方向、边界及版本标识，输出带编号的校验图和展开模板；调整细分等级或切换款式不改变图案位置。白瓷与彩绘交界处保持几何、法线连续。
- 使用图像生成制作平面广彩花纸，保留参考中的花鸟、蝶、枝叶、器物纹样及细金线的密度和构图关系。生成稿不包含杯体透视、摄影背景、投影或固定高光；照片未展示的背面按相同纹样语言延展，并记录为近似重建。
- 每个装饰区域锁定唯一彩色母版，再在相同像素坐标上制作金彩遮罩和叠彩高度信息，由高度信息烘焙法线。粗糙度与 Clearcoat 分区从同一套区域标注派生；不以颜色亮度直接推断浮雕高度。
- 白底、金底共用器型与 UV。杯身分别制作白地和金地材质；把手、杯碟依据原图独立配置，**白底款仍保留金地杯碟装饰带**。
- 采用 `MeshPhysicalMaterial`，分开白瓷、彩绘、金彩、底部釉面及支承接触面。白瓷固定为不透明非金属，`metalness = 0`、`transmission = 0`；金彩使用对齐的金属遮罩，花鸟色彩区域保留非金属响应。底部是否露胎作为可调假设记录。[材质依据](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)
- 支持 Base Color、Normal、Roughness、Metalness、Clearcoat、Clearcoat Roughness 和 Clearcoat Normal。Base Color 使用 sRGB，数据贴图使用线性数据解释；叠彩起伏同步作用于需要体现起伏的外层反射。
- 保留高分辨率母版，运行时提供分级纹理及 KTX2 压缩资源，只加载当前款式所需资产。

对外保留以下最小接口：

| 接口或类型 | 职责 |
|---|---|
| `GeometryParams` | 器型尺寸、波纹、圆角、连接位置和细分等级 |
| `PBRMapSet`、`CupStyle` | 各装饰区域的贴图、材质参数、母版标识及 UV 版本 |
| `setStyle(style): Promise<void>` | 完整材质包加载成功后统一切换，保持几何、相机和观察状态 |
| `replaceArtwork(region, image)` | 单张新图作为普通釉面印花应用，清除该区域旧图案的法线及遮罩 |
| `setView(mode)`、`setLidOpen(open)` | 控制整套、单杯、翻底及杯盖状态 |
| `resetView()`、`dispose()` | 复位观察状态、释放资源 |

换款加载失败时保留当前款式；快速连续切换只应用最后一次请求，并释放失效请求占用的资源。

## 4. 摄影棚与无界面交互

摄影棚使用大型主软箱、侧面长条反射、顶部补光和暗面反光板构造环境，经 PMREM 提供不同粗糙度的环境反射。背景保持深酒红，主照明接近中性，确保白瓷保留本色。[环境反射依据](https://threejs.org/docs/pages/PMREMGenerator.html)

台面使用实时平面反射，并进行低强度混合和柔化；倒影随相机、开盖和翻底状态更新。接触阴影由支持阴影的灯光单独提供。移动端降低反射缓冲分辨率，保留同样的场景关系。[平面反射依据](https://threejs.org/docs/pages/Reflector.html)

| 操作 | 行为 |
|---|---|
| 鼠标拖拽／单指拖拽 | 围绕器物旋转观察 |
| 滚轮／双指捏合 | 缩放，限制穿入器物及过度远离 |
| 点击杯盖或盖钮 | 开合杯盖；开盖沿抬升后移路径露出内腔 |
| 点击把手 | 切换白底／金底，保持当前观察角度 |
| 双击／双点杯身 | 按“整套 → 单杯 → 翻底 → 整套”循环 |
| 双击／双点空白处 | 恢复完整组合和初始视角，保留当前款式 |
| 长按空白处／按 `H` | 临时显示操作说明，关闭后恢复纯器物画面 |

单杯和翻底状态隐藏盖碟，将杯体抬起并转到可观察位置，避免台面遮挡杯底。动作衔接使用可中断的状态动画，快速操作从当前姿态继续过渡；减少动态效果偏好下直接切换。

通过移动距离区分点选和拖拽，多指缩放结束后不触发点选。把手和杯盖使用适度扩展的不可见拾取区域，提高手机操作可靠性。保留键盘等效操作和辅助技术说明。

首版使用 WebGL 实时渲染，按实际帧耗时调整像素比、纹理等级和反射分辨率；静止且无加载、动画时停止连续重绘。中性灰材质检查环境仅在开发检查模式中提供。

## 5. 验收与交付

实施按**器型 → UV → 材质 → 花纸 → 完整交互**依次检查，发现偏差后修正，再进入下一阶段。

- **几何验收：**检查索引、三角面、法线、接缝闭合、最小壁厚及参数边界；用正面、把手侧、俯视、底部和连接根部近景核对参考。侧光旋转时，波纹必须产生连续变化的真实高光。
- **UV 与材质验收：**编号棋盘格检查拉伸、方向、接缝和越界；逐区域叠加检查彩色、金属和浮雕遮罩。对齐检查包含内容边缘，不能仅凭图片尺寸一致判定通过。
- **交互验收：**覆盖桌面鼠标与触屏路径、拖拽后误点、连续换款、加载失败、动画中切换状态、翻底复位和视口旋转；换款过程中几何对象保持不变。
- **视觉验收：**两套款式均保存实际浏览器渲染的整套、侧面、开盖俯视和底部截图，补充把手与波纹近景；确认釉面反光随观察角度变化，金彩与彩绘保持清晰区分。
- **设备验收：**检查 1440×900、1920×1080、390×844、430×932 及手机横屏。覆盖 Chromium 和 WebKit；桌面与手机均以流畅交互为目标，在被测设备上记录帧时间、画质等级与资源占用。浏览器模拟结果和真实手机结果分别记录，未经真机测试不宣称已完成手机性能验收。
- **工程验收：**完成类型检查、生产构建、关键几何及换款测试，检查控制台错误、资源加载、重复换款后的内存趋势，以及 WebGL 不可用时的明确提示。
