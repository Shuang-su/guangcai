# 素材来源、生成与 PBR

参考是用户本次提供的 8 张产品截图。来源文件名、大小及 SHA-256 在 `assets/masters/references.json`；原文件保持不变。截图含平台页面及无关通知，因此交付包只保存来源索引，不复制截图中的私人界面内容。共享链接只作为讨论背景，未引入已有代码或继承未经验证的完成结论。

两张生成母版与完整提示词保存于 `assets/masters/`。杯身母版原生 1774×887 RGBA，装饰带母版原生 2172×724 RGBA。它们依据参考中的广彩花鸟、蝶、枝叶与金线语言重新绘制，包含对不可见背面的近似延展；不是官方花纸的逐笔复制。没有把产品照片贴到杯体上，也没有用程序绘制若干花朵代替生成纹样。

## 运行资源

`npm run assets` 从锁定母版生成 high/low 两档。杯身分别为 1760×880 / 1024×512；装饰带为 2048×384 / 1024×192（母版透明边缘裁掉后重采样）。PNG/WebP 为可直接使用的回退资源；`npm run compress` 使用 Khronos toktx 生成 UASTC KTX2、Zstandard 压缩和 mipmaps。压缩工具可通过 KTX_TOOL 环境变量指定，交付包不附带平台二进制。依赖和压缩工具各自许可见 `THIRD_PARTY.md`。

白地与金地使用同一透明彩色母版，分别填入瓷白与金色底。白地款的把手和杯碟仍使用金地装饰带。首次只加载当前款式，切换时全部区域加载完成后一次性替换；失败保留现有材质；过时请求释放纹理/材质而不覆盖最新请求。

## 同坐标分区

Alpha 定义彩绘覆盖；色相范围的区域标注区分叶、花瓣和近似金线，同坐标生成 height / metalness / roughness / clearcoat。高度不是颜色亮度。高度层为约 0.025 / 0.036 / 0.054 mm 的视觉推定，随后用有限差分烘焙切线空间法线。色相标注是首版近似，尤其黄色花瓣与金线可能有语义混淆；并非手工精修到每个笔触的生产遮罩。所有贴图与边缘对照证据都保留，可继续用人工标注替换 semantic / height。

杯身与装饰带各锁定一张彩色母版，禁止重新独立生成会错位的 normal 或 metalness。Base Color 使用 sRGB；Normal、ORM、Clearcoat 使用 NoColorSpace。ORM: R=1、G=roughness、B=metalness。Coat: R=clearcoat、G=clearcoat roughness。Clearcoat Normal 与底层使用同源法线并降低强度。

白瓷为不透明 MeshPhysicalMaterial，metalness=0，transmission=0，roughness=0.26，clearcoat=0.72。金彩用金属遮罩控制；彩色花鸟处保留非金属响应。侧边金线使用独立金属材质。足部使用较粗糙的非金属表面；是否露胎是待实物核实的假设。

`replaceArtwork(region, image)` 将新图作为普通釉面印花，清除该区域旧 normal、metalness、clearcoat normal，避免把旧图的浮雕套在新图上。

## 摄影棚

五块不同面积与方向的摄影棚反射卡经 PMREM 提供不同粗糙度的环境反射。中性主光配暖色偏低的补光，背景深酒红；主角保持静止。Reflector 使用实时镜像相机，9 点柔化并以低强度混入深色台面，随开盖、翻底和观察角变化。接触阴影由独立支持阴影的方向光产生。它是 WebGL 实时 PBR 近似，不是离线路径追踪、真实多层烧制光谱或经过测量标定的 BRDF。

技术依据：[MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[PMREMGenerator](https://threejs.org/docs/pages/PMREMGenerator.html)、[Reflector](https://threejs.org/docs/pages/Reflector.html)。
