5. 使用 Base Color / Normal / Roughness / Metalness / Clearcoat 数据，玻璃为非金属，金纹与色釉分区。80 张卡片数据贴图按同 UV 比例降至 256×192；卡面 Base Color 为 640×480。全部材料运行文件实际总字节约 2.98 MB（文件系统分配空间不是网络传输量）。
6. 常驻杯体/renderer，路由只改变目标视口及相机构图，约 700ms 过渡；固定材质整包成功后呈现。海报离屏 HDR + ACES/sRGB 导出，不缩放可见画布；原生 PNG img 接管同构图位置。返回、规则与步骤切换不重建杯子。
7. 首页、结果、榜单、规则等采用无字水墨分层素材，融合原有山海设计与 APEC 风格；竖/横构图独立，没有直接使用完整 APEC 海报。三幕开场使用同一滚动进度，光丝/粒子/曲面、独立花鸟蝶图层及白瓷连续承接，可倒退、跳过和减少动态效果。
8. 旧紫色草稿仅清除对应颜色并回到该步；已完成作品保留。旧海报按 `waterink-v2` 更新，保持原 ID 和选择。保留真实错误状态、重试和返回。
