## 已修复问题与工具失败

- 材质 / 海报初版使用离屏 RenderTarget 时输出色调与实时画面不同：改用同一默认帧缓冲色调映射后导出，并恢复相机与渲染尺寸。
- 两个尺寸观察器重复调整画布导致首帧可能空白：改为 H5 适配层统一观察与重绘，增加首帧实际图像检查。
- 彩带水平扫动导致 360 屏宽短暂横向溢出：改成不越界的纵向轻变形与背景扫光。
- 桌面上下分隔装饰压住模型工具：按左右布局隐藏该移动分隔层，实际构建截图复核控件无遮挡。
- WebGL 中断后离开再返回可能复用失效上下文：检测不可用状态并重新建立观察器，故障回归通过。
- 自动化 fullPage 截图会扰动 sticky 开场进度：开场和 WebGL 截图改为原生视口截取。真实页面滚动保持不变。
- 首次录像缺少 Playwright ffmpeg：安装官方包到项目父目录的 `.codex-work/cache/playwright` 后重跑通过。
- npm 原先误选平台可选包：使用 arm64 安装参数恢复。当前 npm 对安装脚本给出提示，未改全局批准策略；本次构建、Sharp 解码与浏览器检查均成功。
- 首次格式化碰到 macOS `._` 元数据文件：增加 `.prettierignore` 排除，实际源码重新格式化完成。
