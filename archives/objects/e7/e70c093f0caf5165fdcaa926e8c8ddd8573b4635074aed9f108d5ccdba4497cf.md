# 本轮有效实施方案

1. 读取四张新参考。对后缀 JPG、实际 HEIF 的暗场参考仅作无损源文件保留及派生 JPEG 预览。
2. 将卡片区域装饰改成七条独立开放曲面：花瓣形宽头、窄颈、扭转面及横向相互穿插的宽带。沿边缘和卡片背后组织，交互仍由 HTML radio 承担。
3. 独立制作飘带 Base Color、Normal、Roughness、Metalness、Clearcoat 文件及原创云纹 SVG；采用玻璃透射与专用反射环境，保持杯体照明独立。
4. 五片换组遮挡曲面仍按左向右覆盖，使用同一材质风格，覆盖时切换内容，随后露出新卡片。
5. 暗场采用彩色细光丝和柔光层，收圆时回到浅金色，保留实际杯口投影和杯盖、碟子的连续组变换。
6. 修复实看发现的选择、换组结束时重复重建 DOM 引起的普通图片卡片闪现；只在真正更换步骤时重建选项。
7. 构建并实测当前 5178 预览，验证五步、透射卡片、规则返回、开场衔接、成果、视口与控制台；保留实际录屏、截图、资产哈希和交付说明。真机 GPU 验收继续单列。
