# 国瓷永丰源「广彩传承」交互式陶瓷展示

Vite + TypeScript + 原生 Three.js。默认只有深酒红摄影棚中的完整杯、盖、碟；无常驻 UI，灯光与器物静止。两套广彩纹样依据照片生成，器型为可调参数化重建。

![金地款实际浏览器截图](evidence/chromium-gold-hero-1440x900.png)

## 直接看交付静态包

完整 ZIP 内已经附带 `dist/`，不需要安装依赖。安装 Node.js 20.19+ 后：

```sh
node tools/serve-dist.mjs
```

访问终端显示的 `http://127.0.0.1:4173`。macOS 也可双击 `Start.command`。不要用 `file://` 直接打开 HTML：WebGL 贴图与解码器需要 HTTP。窗口关闭后停止本地服务；没有云端服务、账号或外部运行时素材依赖。

## 开发与构建

```sh
npm ci
npm run dev
npm test
npm run check:assets
npm run build
npm run serve
```

项目锁定依赖见 `package-lock.json`。使用 Node 20.19+ 或 22.12+；不要把其他架构安装的 node_modules 直接复制过来。`npm run assets` 重建未压缩贴图及 UV 模板，`npm run compress` 用 KTX-Software 4.4.2 的 toktx 生成压缩版本。可设置 `KTX_TOOL=/path/to/toktx`。生成工具未运行也可直接使用已附带的生产资源。

## 操作

| 操作 | 结果 |
| --- | --- |
| 鼠标拖拽 / 单指滑动 | 环绕观察 |
| 滚轮 / 双指捏合 | 缩放 |
| 点杯盖或盖钮 / L | 抬升、后移开盖，再次关闭 |
| 点把手 / S | 白地、金地切换 |
| 双点杯身 / V | 整套 → 单杯 → 翻底 |
| 双点空白 / R | 回到完整组合与初始视角，保留款式 |
| 长按空白 / H | 临时操作说明；可按 Escape 关闭 |
| 方向键 / +、− | 键盘旋转与缩放 |
| P | 导出当前画面（开发环境写入项目本地 QA 目录） |

手机和桌面共享状态与手势逻辑。拖动超过阈值不会触发点选，多指操作结束不触发换款。减少动态效果偏好下直接切换姿态。无 WebGL 时显示明确提示。

## 工程分层

- `src/geometry/`：截面、带状扫掠、闭合杯体、圆形盖碟、参数与装配。
- `src/materials/`：PBR 资源加载、贴图颜色空间、原子换款和资源释放。
- `src/styles/`：款式目录、PBRMapSet / CupStyle 合约与 high/low 资产路径。
- `src/studio/`：软箱环境、PMREM、接触阴影、实时柔化倒影。
- `src/interactions/`：手势、临时说明、可中断姿态动画。
- `src/main.ts`：组装、加载、渲染调度、质量降级、开发检查入口与生命周期。
- `assets/masters/`：生成母版、语义/高度图、提示词、来源哈希。
- `assets/uv/`：真实 UV 边界、编号检查图、UV 版本与参数快照。
- `public/artwork/`：两档 PNG/WebP 和带 mipmaps 的 KTX2。
- `evidence/`：真实浏览器截图和机器可读验证结果。

## 最小外部接口

加载后通过 `window.cupViewer` 使用以下接口。示例对象直接执行即可；TypeScript 类型定义见 `styles/catalog.ts` 和 `geometry/parameters.ts`。

```ts
await window.cupViewer.setStyle('white'); // 或完整 CupStyle
window.cupViewer.setView('single');      // assembly | single | bottom
window.cupViewer.setLidOpen(true);
await window.cupViewer.replaceArtwork('body', file); // body | handle | saucer; File/Blob
window.cupViewer.resetView();
window.cupViewer.dispose();
```

`setStyle` 完整成功后统一替换；失败返回 rejected Promise 并保留当前材质；并发时仅最后请求生效。`replaceArtwork` 只应用普通釉面印花，删除旧花纸的浮雕与金属遮罩。它不会重新建模或移动相机。

开发服务 `?debug` 打开器型校准与 UV/法线/中性环境检查。参数重建是显式开发操作；正常换款不触发重建。`?style=white`、`?view=bottom`、`?open`、`?camera=front|side|top|detail` 可用于可复现取景。`inspect()` 返回诊断统计，`camera(position,target)` 可设置检查角度。
