# 完成记录：线条层次、亮暗反光与邻近部件倒影

完成日期：2026-10-11（本地）。项目为非 Git 独立预览副本；未初始化 Git，无法创建 checkpoint commit。原项目及原始资料保留。

## 实际结果

遵照后续反馈，以用户选择的最早金属版本为视觉基准。保留可辨认的屋檐、窗格、门板与砖线，减轻深暗反光并增强亮边。金属底面粗糙度 0.26、原线条平滑过渡到 0.22，恢复早期线条高度轮廓与 0.70 法线强度。金属填色与线条高度保持独立，整片底面位移仍为 0。

杯身现在使用包含真实把手、杯盖和杯碟的局部反射。捕获时排除接收倒影的杯壁和地面，使用 512 像素半浮点 CubeCamera 及 PMREM，再在靠近把手的方向做有限范围视差校正。相机旋转复用捕获；部件姿态稳定后重新捕获；切回完整材质时刷新，避免使用诊断材质的反射。材质校准新增“邻近部件反射”开关。

白瓷上的把手倒影强度较轻，属于当前视觉参数选择。此实现是单探针的局部近似，不能等同于离线逐像素光追或多次反弹，也不保证参考中的倒影位置、形状与强度已完全匹配。

## 过程修正与边界

最初候选使用 0.40/0.28 粗糙度和更强法线，用户随后明确偏好早期效果，故收回该方向。候选导出曾因 5 与 5.0 文件名不一致而无法载入，修正后重跑；最终程序与最终验证均通过。

固定花纸本轮没有重生成；城市线条与底部定位保持原基准。PSD 文字“中国 / CHINA”与参考“中国 / China”差异继续保留。模型与花纹仍存在上一轮已记录的参考重建差异。没有真实手机／Safari 实机验收，没有推送、部署或改动生产工艺尺寸。
