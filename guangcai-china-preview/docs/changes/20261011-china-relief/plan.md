## 2. 效果图的核验结论

**能确认凹凸细节与原线稿高度对应，但不能仅凭这张效果图断言“只有线稿处凸起，其余位置完全没有高度”。**

- **金属覆盖范围：** 天坛的屋面、墙面、门板，以及长城山体内部，都呈现连续金色；金属区域明显大于 PSD 的笔画区域。

## 3. 修订后的浮雕制作方法

采用三份相互独立、像素对齐的数据：

| 数据 | 来源与用途 | 本轮默认 |
|---|---|---|
| 线条凹凸遮罩 | 从建筑图层的透明度提取，决定细线起伏 | 原线条形成克制的凸纹 |
| 金属覆盖遮罩 | 依据建筑外轮廓及效果图制作，决定哪里呈现金属 | 建筑内部连续金色，建筑之间保持白瓷 |
| 文字遮罩 | 从独立文字图层提取 | 固定金色，与城市换色分离 |

具体流程：

- **直接读取原图层。** 保留原始位置、比例和抗锯齿，不从白底合成预览里重新抠线，也不让图像生成重画建筑。
- **先检查透明度质量。** 广州塔等图层存在低透明度残点，需要清理后对照原稿，防止残点变成表面颗粒，同时保护细线和交叉网格。
- **从线条制作高度与法线。** 使用“透明度遮罩 → 温和的边缘圆滑 → 高度场 → 法线贴图”的流程，不把金色 RGB 的明暗直接当成高度。
- **单独制作金属填充。** 按各建筑外轮廓确定金色内部；保留楼与楼之间的空白，不对整张线稿盲目填洞。
- **本轮优先使用贴图表现浅浮雕。** 高度场驱动细节法线，杯模不因城市图样变化而重建。取消上一版“一开始就强制加密曲面并做真实位移”的要求；高度源文件继续保留。
- **凹凸方向先做局部对照。** 用同一机位和灯光比较线条凸起、线条凹入两种结果。默认采用凸纹；若参考仍无法明确区分，保留该默认并标注为视觉近似，不将其写成已确认工艺。
- **金色底面位移默认归零。** 先匹配连续金属面与线条起伏；不添加缺乏依据的整片建筑厚度。

文字继续采用 PSD 原稿。效果图中的英文为 `China`，PSD 为 `CHINA`，将此差异记录下来，本轮保留 PSD 字形及大小写。

## 4. 固定花纹、替换接口与本轮范围

本轮仍只完成**中国临时稿的效果校准**，城市选择和换色界面留到下一轮。

- 把手后方纵向饰带、把手装饰面、杯碟外圈按新版参考重建，保存为固定花纸资产；沿用原版密铺、细描线、无烘焙高光的制作要求。
- 杯模、分区 UV 和观察交互沿用现有基础。先匹配参考机位，再调整确有差异的器型参数。
- 城市包包含金属覆盖、线条凹凸及相关材质通道；文字独立管理。`applyCityArtwork(pack)` 只更新城市区域，固定广彩和文字保持稳定。
- 后续“只换贴图”指替换一组对齐的城市材质贴图；新 PSD 修订稿可重复执行导出流程，无需重新建杯。
- 未来换色只改变城市图样，文字、白瓷和结构金边不随之改变。
- 原 PSD、旧花纸与旧项目保持原样，在外置盘独立预览副本中交付。当前项目为非 Git 目录，保存完整变更记录，不自动初始化 Git。

## 5. 验收与交付

1. **源稿一致性：** 导出线条与原 PSD 叠加检查，确认建筑、细线和文字未位移、漏失或被重新描画；辅助外框不进入材质。
2. **凹凸与金属独立：** 关闭凹凸时仍有连续金色建筑面；关闭金属检查线条起伏时，不应出现整片建筑被错误抬高的效果。
3. **细节对照：** 重点核对天坛屋檐、门窗、广州塔网格和长城砖线；保留局部凸／凹对照与默认参数。
4. **曲面与固定装饰：** 检查建筑面、文字面、把手侧和杯碟整圈，确认无异常拉伸、接缝、闪烁或覆盖留白。
5. **替换验证：** 城市贴图替换后，几何、固定花纹及文字颜色保持稳定；加载失败保留当前完整版本。
6. **交付证据：** 提供本地三维预览、固定花纸、从 PSD 提取的遮罩、高度与法线源文件、双面同机位对比，以及明确区分“文件实证、图像观察、视觉近似”的完成记录。

这份修订计划取代上一版；核心调整是：**直接利用 PSD 的真实线条制作凹凸，把金属填色单独处理，不再预设整片建筑都需要凸出。**
