## 观察结论与边界

**文件实证**：当前 PSD 是可解码的像素图层交付，没有可用编辑路径或矢量蒙版；不能反推作者从未使用钢笔。原线条位置来自 PSD，不是图像生成重描。

**图像观察**：原效果图金属覆盖大于笔画范围，建筑内部为连续金色；细线有配对明暗。城市金属较把手和结构金边更柔和，本次按该反馈校准。

**视觉近似**：金属轮廓闭合、哑光参数、凸／凹方向、城市组在杯面的大小、固定花纸的重建均为可修改预览参数。真实基底厚度和工艺凹凸尚不能从单图确定，金色底面位移默认 0。

保留差异：PSD 中广州塔相对天坛更高，与暂时效果图不完全一致；PSD 文字为“中国 / CHINA”，参考为“中国 / China”。不改原字形与建筑内部比例。器型沿用旧实拍基础；新参考中的盖钮、盖缘、把手曲线仍有局部差异，未根据单张图强行改变隐藏结构。固定花纸与参考具有可见构图／配色差异，当前是风格及区域重建，非官方花纸精确复原。

近似参考机位用手工选取的杯盖与杯碟边界拟合，建筑面 RMS 2.736 px、文字面 1.441 px，仅衡量选中的 8 个投影边界值，不代表整个模型／图案逐像素一致。参考只裁切，模型独立渲染；叠图是 50% 算术混合。

设备边界：手机验收为 Chrome 模拟视口与触摸，没有声称真实 iPhone／Android 或 Safari 实机通过。正式城市资产、最终工艺尺寸、生产部署和换色 UI 留给下一阶段。
