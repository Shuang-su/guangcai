# 中国杯 3.0：原始花纸、白瓷光效与移动端背景

本版采用你确认的 **450 ml 杯窄饰带、把手花条和 151 碟花带**，以最后两张单杯效果图校准白瓷、杯盖和首页视角。保留现有城市金色浮雕及已接受的花纹凹凸深浅，完成后发布到独立新网址，当前站点继续保留。

## 1. 原始花纸接入

已直接读取“广彩花纸”文件夹中的 8 份 PSD，无需 Photoshop。“导出图.psd”为 **6409 × 3858 的 CMYK 合成稿**，嵌入 `Japan Color 2001 Coated` 色彩配置，明确包含本轮需要的三个装饰区域；其余文件保留分层花鸟素材。

- 以“导出图.psd”的完整排版为制作依据，按嵌入的色彩配置转换为 sRGB，保留原件、转换母版、裁切坐标和来源记录。
- **杯身饰带：** 提取标注“450 ml 杯”的窄饰带，保留原花鸟排列与把手连接处的留空，按新单杯参考校准可见宽度。
- **把手花条：** 使用标注“450 杯把”的独立长条，按把手表面的实际长度展开，校准首尾方向和花朵尺度。
- **杯碟外圈：** 将“151 碟”的弧形花带按弧长展开，再连续绕满杯碟一周。取消这套新花纸上的四段镜像重复及旧相位补偿，按参考图定位花鸟顺序和接缝。
- 使用区域轮廓排除标注、纸张空白及与模型金边重复的印刷边线；保留图案内部的白色花瓣。
- 从新花纸生成像素对齐的法线、高度、粗糙度及金属区域。延续现有凹凸方法和强度：**花纹法线 4.4、清漆法线 2.4**，以灰模近景校准换稿后的视觉深浅。旧花纸及其凹凸贴图留作对照。

## 2. 白瓷、杯盖与参考视角

当前背景只改变页面底图，三维灯光保持原样；杯身的大部分白瓷与城市金色图样共用材质，因此需要按白瓷区域单独调整。

- 建立统一的白瓷校准参数，覆盖杯身、杯盖、盖钮白瓷及杯碟内侧；杯身通过现有城市／文字金属遮罩排除金色部分。
- 调整白瓷底色和间接补光，让杯身形成新参考图中的柔和明暗过渡，杯盖出现清楚、柔和的釉面亮区。保留接触阴影、轮廓和釉面反射，避免提亮后失去体积。
- 杯盖使用独立的白瓷反射设置校准顶部亮面。与现有杯身局部反射逻辑组合，保留把手在杯身附近的反射。
- **锁定全局曝光 1.08、城市金色和结构金边的材质参数、城市法线强度及城市／文字贴图。** 背景切换继续只影响画面底图。
- 新增最后两张单杯图对应的左右机位。先通过杯盖、杯底和碟沿轮廓匹配透视，再校准饰带和花纹定位；本轮沿用器型尺寸。
- 首页“建筑面”“文字面”采用新参考的观察方向和透视关系，在手机上重新适配完整器物及操作区。旧双杯图继续用于城市图样位置核对。

## 4. 验收与对照

保留改动前基线，按以下项目验证：

- **同机位叠图：** 对两张新单杯参考分别保存并排图、50% 叠图和滑杆对照，核对杯盖、碟沿、饰带宽度、主要花鸟的位置与尺度。参考图中的空白杯身用于器型和白瓷比较，城市图样按原双杯图检查。
- **白瓷提亮：** 同一机位检查调整前后杯身与杯盖，确认灰感减轻、釉面亮区更接近参考，亮部保留层次；旋转后明暗与反射仍自然变化。
- **凹凸与金色回归：** 对城市贴图和关键材质参数做一致性检查；对新旧花纸分别保存彩色、灰模及关闭凹凸的近景，确认凹凸跟随新图案，深浅维持当前接受程度。
- **映射与交互：** 检查杯碟整圈接缝、鸟蝶方向、饰带边缘及把手连接处；验证城市包替换、加载失败、连续切换、右键拖移和双指拖移。
- **移动端与性能：** 检查窄屏手机、常用手机、横屏和平板／桌面视口，验证默认背景、旧背景、上传、复位及视角切换。记录同条件冷加载时间、首屏资源量和近看清晰度，检查控制台及网络错误。

浏览器移动视口验证与实际手机验收分别记录；同机位对照作为视觉判断依据。
