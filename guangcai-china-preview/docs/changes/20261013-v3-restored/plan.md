# 固定纹样高清重建

1. 针对 195px 高原稿的细节上限，使用内置图像生成进行分段高清重建。原稿约束整体构图、花鸟身份、位置、配色和边缘裁切；生成新增描线/笔触明确标注为重建，不宣称无损复原。
2. 杯碟长带按有重叠的连续区段制作高清母版，周期接合并检查每个连接。杯身窄饰带与把手条分别处理。保留原稿、每段输入、生成输出、提示词和对位参数。
3. 杯碟采用两行带护边的纹理图集承载约 16K 单周有效像素，避免单张纹理超过 8192 宽；原几何与城市 UV 不变，所有花纹通道采用同一图集映射，保留旧包兼容。
4. 从高清描线制作平滑而清楚的凸纹：分开彩釉底面、描线脊部与金底；不直接把绘画明暗当作全部高度。使用高精度高度/法线，保留原城市、文字、白瓷、器型、曝光及背景。
5. 对比最新线上基线，检查彩色/灰模/关闭凹凸近景、各分段连接与完整器物。验证图集护边、方向、材质一致性、城市替换/快速切换/失败保留、桌面和模拟手机。
6. 真正改善后手动更新独立 v3，公开同机位证据，保留旧部署档案；Git 不连接 Netlify 自动部署。
