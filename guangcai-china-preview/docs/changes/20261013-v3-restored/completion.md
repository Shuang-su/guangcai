# 固定纹样高清重建与连续凹凸

## 本轮完成的内容

原始碟花带有效采样只有 6924 × 195。上一版提高了法线数值精度，但无法补回颜色线条缺失的细节。本轮根据用户授权，用内置图像生成对固定花纹做高清重建：9 段杯碟、1 幅杯身饰带、2 段把手条。原输入、12 份生成输出、提示词、对位报告和来源哈希均保留在 `assets/masters/v3-restored`，原 PSD 不改。

- 杯碟连续母版 16256 × 512，运行时为带 32 像素护边的 8192 × 1152 两行图集。各通道使用同一布局，周期边界位于连续花叶内部，未使用四段镜像。
- 杯身饰带 1024 × 2466，把手花条 384 × 4473；原把手连接留白按源稿遮罩保留。
- 粗对位约束大构图，重叠区域按最小差异路径接合。描线高度使用连续墨线遮罩与温和圆滑，降低原来的颗粒、断续高光；保留釉彩面、描线脊部和金底的区别。
- 浮点高度求导，保存 16 位高度母版和 RGBA16F 法线。颜色及其他通道无损 WebP；运行时贴图总量 51,952,141 字节。按要求优先质量，未为首屏压低纹样密度。
- 法线强度 4.4、清漆法线 2.4 保留，但高度分布按新描线重新制作；不声称新旧每个像素的凹凸完全相同。
- 增加可选图集参数及显式纹理梯度采样；PBR、粗糙度、金属度、法线、清漆法线、灰模检查保持对齐。旧包省略图集字段时使用原映射。
- `npm run textures:fixed` 从已保存的高清母版重新编译；原稿导出与旧 HQ 派生保存在显式 `textures:fixed:legacy` 命令。生成步骤不会在构建或网页加载时重新调用。
- 城市/文字 12 份文件和 9 份器型、白瓷、灯光、反射、背景实现按上一部署源提交哈希逐个核验。城市金色、结构金边、曝光 1.08 未调整。

## 验证与证据

- 17 项单元测试：11 项几何、4 项半浮点解码/方向、2 项图集边界。
- 9 项固定包测试：原 UV、图集安装、非法图集原子拒绝、旧包兼容、失败保留、快速切换最后一次生效。
- 53 项三维交互测试：城市换包、文字颜色稳定、法线开关、反射、视角、右键和双指拖移、缩放及释放；零浏览器错误。
- 40 项资源核验：通道尺寸、16 位高度、全部护边像素及半浮点护边一致、源文件保护范围。44 个母版/输入/提示词文件和最终输出均记录 SHA-256。
- 图集与同内容完整长图的实际 PBR 渲染逐像素比较：完整分辨率误差为零，缩小后平均误差 0.052/255，分行边界平均 0.071/255；包含正常和清漆法线。
- 本地交付检查 14 项通过：默认背景、旧背景、灰色背景、手机模拟、盖钮倒影、全部对照图解码及滑杆。无浏览器或网络错误。
- TypeScript / Vite 构建通过；16 个运行时贴图解码无损一致。
- 同机位保存上一版/本版花瓣、首尾、鸟纹的彩色、灰模、关闭凹凸；检查九处连接和完整器物。新单杯参考的左右并排、50% 叠图也已刷新。

## 视觉边界与过程中的失败

这是按原稿约束的生成式高清重建，不是无损恢复原 PSD 中不存在的像素。花鸟顺序与主体布局保留，局部描线、花瓣形态、晕染和色彩有细微差异；极端近看仍可能辨认段间笔触差别。接缝通过周期母版和护边消除明显硬切口，不宣称每处画笔轨迹达到人工矢量重绘水平。

前期试片的渐变墨线高度出现颗粒状起伏，已改为连续线条遮罩并重新检查灰模；试片保留在项目缓存，不作为发布结果。读取上一版 immutable URL 一次 DOM 导航超时，改为在本地以未激活新包前的旧花纸和相同材质渲染基线，已在 capture.json 明确记录，不将其说成远程截图。实测 Chrome 桌面及手机模拟，真实手机与 Safari 仍待验收。城市、器型与金色已有的离线参考差异继续保留。
