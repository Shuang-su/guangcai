# 校准步骤

1. 保留当前线上 v4 的源码、同机位渲染和部署证据。
2. 用既有相机标定做原图 / 当前渲染 / 50% 叠图；分别检查图样位置、花带比例和材质凹凸。标定仅拟合杯盖和杯碟边界，不将其称为全画面精确配准。
3. 对同一 v4 花纸比较当前釉层、较早釉层、平衡釉层；测量纹理法线强度变化。只调整确有依据的部分，保持颜色母版、城市包及加载优化。
4. 保存局部法线开关对照与多角度截图；验证主要交互与城市替换隔离。
5. 更新对照页，构建、上线到既有中国站并回读远端状态和实际渲染。非 Git 项目保留完整文件记录，不初始化 Git。

## 最终选择

- 用户确认针对彩色固定装饰，又要求比中间灰模更深。最终固定法线 4.4、釉层法线 2.4，保持釉层覆盖 0.75、清漆粗糙度 0.14、specularIntensity 0.85。
- v4 颜色母版和颜色/粗糙度/金属数据不变；v5 增补局部彩色描线的高度/法线，后续深度调整只改材质强度，不增加贴图流量。
- 花纹近看、固定起伏开关、中性灰花纹检查独立于城市凹凸。移动端视角按钮改四列，避免遮挡材质入口。
