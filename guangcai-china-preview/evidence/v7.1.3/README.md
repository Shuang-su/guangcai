# V7.1.3 制作、尺寸与兼容记录

固定花纸参照五张 iPhone 13 mini 实拍，来源与原件 SHA-256 见 [references/sources.json](references/sources.json)。预览副本仅调整 EXIF 方向与尺寸，未重绘。白瓷连接件保持原几何。

## 本轮资源

- [resource-build.json](resource-build.json)：原稿、修正层与派生输入哈希，两个限定种子区域，逐档生成物。
- [resource-validation.json](resource-validation.json)：195资源逐项、9新文件、216历史文件不变、母版保护区与三级孔位法线验证。
- 修正层：`assets/masters/v7.1.3/body-hole-mask.png`，只覆盖原稿两个预留孔。原图637×1534，连接区域种子(315,180)/(315,1010)，边界窗口分别[210,85,426,308]/[210,910,427,1118]。孔区域内部阈值用于种子连通提取，不搜索全图白色。颜色/ORM护边2原始像素，法线4像素消除旧轮廓；完整遮罩可单独复核。
- 金底 RGB[255,200,70]，ORM[255,56,255]，法线中心(0.5,0.5,1)。只在修正层内改母版。颜色仍WebP quality88，ORM无损，HFN1高精度。全图重编码使颜色压缩边界附近可能有小幅误差；母版遮罩外严格字节不变。
- 三档杯身425×1024、850×2048、1024×2466。花纸UV镜像由manifest控制；复用把手/杯碟纹理，不增加一套镜像贴图。杯碟在逻辑U变换后再分图集，保留护边与分区顺序。
- 法线切线基由变换后UV的导数生成；基础法线和清漆法线共享texture矩阵。不得额外将X分量反号，否则会重复翻转。

## 版本恢复

`v7-4` manifest的可选字段 `fixedMapping: source-layout-v4`控制三个部件的镜像与杯身底边；缺省`source-layout-v3`。作品仍只保存releaseId和既有参数。导入先锁定编辑/导出、显示加载层、取消旧提清/切城，保留旧资源引用。新固定花纸、当前高清城市、六组文字、杯底标识全部下载、解码、GPU初始化后才切换。失败释放候选并恢复旧花纸/版本；WebGL丢失取消导入，从最后已提交作品轻量重建。恢复期间不发混合版本onDesignChange。接口仍返回Promise<boolean>，错误拒绝Promise；并发导入明确拒绝，可等待上一调用结束后重试。

## 复现
